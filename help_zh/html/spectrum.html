RTA 窗口


RTA 窗口用来生成实时分析仪（Real Time Analyser，RTA）图或频谱分析仪（spectrum analyser）图。REW 一边分析输入信号，一边实时更新图形。点击 REW 主窗口工具栏上的 RTA 按钮，即可打开这个窗口。

点击图表区右上角的记录按钮 ，即可启动 RTA，图上随即出现 RTA 曲线。此后 RTA 会一块接一块地连续分析输入采样数据，并显示每一块数据的频谱（spectrum）。

如果按当前 RTA 设置，更新间隔超过 1 秒，记录按钮上会显示进度百分比。

分析仪有时不用测试信号，例如用来查看背景噪声里含哪些频率成分。但更常见的用法，是配合 REW 的信号发生器、外部信号发生器或其他信号源一起使用。

如果信号发生器播放的是粉红噪声（pink noise），RTA 显示的就是房间的频率响应，而且实时更新。这样一来，修改 EQ 设置的效果马上就能看到。用粉红周期噪声（Pink Periodic Noise）效果更好。

用信号发生器播放正弦测试音，可以在分析仪上观察测试音及其各次谐波（harmonic）的电平，REW 还会算出失真百分比。改用信号发生器的双音信号，则可以测量互调失真（intermodulation distortion）。

RTA 图上显示两样东西：一是当前选中的测量，作为参考；二是实时的 RTA 或频谱。

图上还有一条峰值曲线，用重置平均按钮可以把它清零。如果启用了反 C 计权补偿（inverse C compensation），曲线读数后会显示对应的图标。如果载入了麦克风校准文件或声卡校准文件，计算结果时会应用这些校准文件。


记录按钮左边显示当前的输入 RMS 值，单位随 Y 轴设置而定，可以是 dB SPL、dBFS、dBu、dBV、dBW、volts 或 watts。这个数值不含信号里的直流（DC）成分。不计权的 RMS 值下方，显示 A 计权和 C 计权（A／C weighting）的值。如果启用了失真低通、失真高通中的一项或两项，这三个数值都只在它们限定的频率范围内计算。

再往下是最近一个 RTA 数据块里的峰值采样值，单位 dBFS。它下面是不计权的带内 RMS 电平（22.4 Hz 至 22.4 kHz）；采样率高于 44.1 kHz 时，还会显示带外 RMS 电平（> 22.4 kHz）。

如果检测到输入削波（clipping），RMS 值会变成红色。RTA 处于 1 倍频程模式时，RMS 值下方还会显示噪声准则（Noise Criterion，NC）和噪声评价数（Noise Rating，NR）的数值。

Y 轴有一个 dBc 选项：它把输入的峰值电平定为 0 dBc；失真面板打开时，则把基波（fundamental）的峰值定为 0 dBc。

Y 轴还有一个 volts/√Hz 选项，用来显示幅度谱密度（amplitude spectral density）。这个选项只在频谱模式下才有意义。

输入选择

点击输入选择按钮，可以更换 RTA 当前使用的输入：


点击后会弹出输入选择对话框。对话框里还有一个按钮，用来查看当前生效的麦克风校准数据。


使用多通道测量（专业版升级功能）时，对话框里有一个选项，可以选多个输入，并指定对其中哪几个输入求平均。RTA 用平均结果画出图上的曲线。

除平均曲线和峰值曲线外，还能分别显示各个输入的曲线，最多 16 条，具体条数在设置 → 视图中设定。

点击配置平均按钮，可以在采集前或采集过程中设置各输入的权重（weighting）和 SPL 对齐。


多通道 RTA 测量的保存格式与多通道扫频测量相同，所以采集完成后，同样可以调整它们的权重和 SPL 对齐。

如果勾选了输入保存为独立测量，保存当前结果时会生成一条平均值测量，并为每个输入通道各生成一条测量。

做多通道 RTA 测量时，如果只选了两个输入，失真和电平会按输入分别显示。

勾选虚拟平衡输入后，会多出一个平衡输入选择框。REW 按模式设置，把平衡输入与测量输入相加或相减，再把结果乘以 0.5。

差分模式模拟的是平衡输入的工作方式。如果送入平衡输入的是一路反相信号，就适合用这个模式。例如在信号发生器上勾选反相第二输出，得到的就是这样的信号。


校准输入电平

RTA 运行时，点击图表上方的校准电平按钮，可以校准当前测量输入通道的输入电平。

校准时，要给输入接入一个 RMS 电压已知的信号，再在校准对话框里填入这个 RMS 电压值。




填好数值后，REW 会弹出确认信息，说明这个输入在达到数字满量程（digital full scale）、开始削波之前，最高能接受多大的峰值电压和 RMS 电压。输入路径上任何一处音量控制的设置改动后，都要重新校准。

如果已经知道输入灵敏度（包括音量控制设置的影响），可以直接在满量程正弦波 Vrms 标签下方的文本框里输入。点击文本框左上角的三角形，会弹出一份预设值列表，可以直接选用；列表里的名称和数值都可以按需修改。


满量程输入电平也可以这样填：在输入选择对话框里点击校准数据按钮，打开校准数据设置，里面有一个满量程正弦波 Vrms 字段。

这个电平作为该输入设备校准数据的一部分保存下来。以后只要在设置 → 声卡里选中这个输入设备，就会使用它。


把结果保存为测量

点击保存当前结果的按钮（快捷键 Alt+S），会把当前显示的内容转成一条测量，放进测量面板。转换按分析仪当前的模式进行：分析仪处于频谱模式，保存的测量就是频谱；处于 RTA 模式，保存的就是 RTA 结果。

保存下来的测量，可以作为后续频谱 / RTA 测量的参考。如果当时有失真数据，会一并复制到这条测量的备注区。

峰值数据也可以用同样的方法保存，点击峰值按钮即可；点击两者按钮，则同时保存当前结果和峰值。

处理 WAV 文件

RTA 也可以分析 WAV 文件，一次一个或一次一批都行。把文件拖放到 RTA 窗口上，或者点击打开 WAV 文件的按钮（快捷键 Alt+O）选择要处理的文件，都可以。

随后会弹出下面这个对话框，用来确定每个文件怎么处理。处理结束时，REW 按所选项把当前结果、峰值结果或两者保存为测量。


频谱 / RTA 图表选项

这张图的图表选项如下。


模式可以设为 Spectrum（频谱），得到频谱分析仪图；也可以设为 1 倍频程到 1/48 倍频程之间的各种 RTA 分辨率。

频谱模式和 RTA 模式的区别，在于信息的呈现方式。频谱模式把信号的频率成分划分成一个个频率区间（bin），每个区间的宽度（以 Hz 计）都相同。例如 FFT 长度为 64k、采样率为 48 kHz 时，每个区间宽 0.732 Hz。图上显示的是每个区间里的能量。

RTA 模式的区间宽度是倍频程的几分之一，所以以 Hz 计的宽度随频率变化。例如 1 倍频程的 RTA 图，在 100 Hz 处的区间宽 70.7 Hz（从 70.7 Hz 到 141.4 Hz），在 1 kHz 处宽 707 Hz（从 707 Hz 到 1.414 kHz）。图上显示的是每个区间内各频率能量的总和，这更接近人耳对声音的感知方式。

由于呈现方式不同，频率成分分布较宽的信号，在两种图上看起来也不一样。最典型的例子是白噪声（white noise）和粉红噪声。白噪声在每个频率上的能量都相同。频谱图显示的是每个频率上的能量，所以白噪声在频谱图上是一条水平线。在 RTA 图上，白噪声却是一条随频率升高而上升的线：RTA 的区间越往高频越宽，覆盖的频率越多，能量也就越多。频率每升高一倍，区间宽度也加倍，能量随之加倍，在我们用来表示电平的对数坐标图上就是增加 3 dB。白噪声听起来“嘶嘶”声很重，人耳感觉它的高频能量更多。

频率每升高一倍，粉红噪声的能量下降 3 dB。在频谱图上，它是一条以每倍频程 3 dB 的速率下降的线。在 RTA 图上，它是一条水平线，因为信号能量下降的速率，正好与区间变宽的速率相同。人耳感觉粉红噪声的能量在各频率上分布均匀。

单频信号是个特例。它的能量全部集中在一个频率上，所以在两种图上显示的电平相同。

在频谱图上，单频信号是一条竖线。在 RTA 图上，它（通常）是一根横条，宽度等于该频率所在区间的宽度。由于能量全部集中在这一个频率上，横条的高度与频谱图上那条竖线的高度相同。

曲线可以按平滑框的设置做平滑处理（smoothing）。

FFT 长度

FFT 长度决定分析仪的基本频率分辨率（frequency resolution），频率分辨率等于采样率除以 FFT 长度。最短的 FFT 是 8,192 点（常简写为 8k），这也是送进分析仪的每块输入数据的长度。采样率为 48 kHz 时，8k FFT 的频率分辨率约为 6 Hz。

FFT 长度加大后，分析仪开始让相邻的 FFT 相互重叠：每来一块输入数据，就算一次新的 FFT。重叠率在 16k 时为 50%，32k 时为 75%，64k 时为 87.5%，128k 时为 93.75%。对数据加窗时，重叠能保证频谱细节不被漏掉。

FFT 长度较大时，可以用下文的最大重叠率限制允许的最大重叠，减轻处理器负担。

平均

图上可以显示正在分析的实时输入，也可以显示多次测量求平均后的结果。显示哪一种，由平均次数下拉框的选择决定。

选一个数字，REW 就对这么多次测量求平均得出结果。每加入一次新测量，最旧的一次就从平均中移除。

还有几种 Exponential（指数）平均模式，越新的输入占的权重越大。下拉框里显示的数字，是加入新测量时旧值保留的比例。数字越大，平均的作用越强。

另有一种 Forever（持续）平均模式，对上次重置平均以来的全部测量按相同权重求平均。用 Forever 平均时，勾选停止于，可以让 RTA 在平均次数达到设定值时自动停止。

启动 RTA 或更改 FFT 长度后，平均不会立即开始。收到的数据要达到一个 FFT 长度与输入、输出缓冲区长度之和，平均才开始。

图表上方的重置平均按钮用来重新开始平均（快捷键 Alt+R）。使用 RTA 期间，如果启动了信号发生器，或者在信号发生器运行时改了它的设置，平均会自动重置。

用粉红噪声测量，或者被测信号里有噪声时，都需要平均。

请注意，用粉红噪声测量响应时，用 REW 的周期性噪声（periodic noise）信号效果最好。如果被测系统无法直接连接运行 REW 的电脑，可以在信号发生器里把这些信号导出为 WAV 文件，做成测试碟来播放。

窗函数

FFT 的分辨率还受窗函数设置的影响。

Rectangular（矩形窗）的频率分辨率最好，但只适用于两种情况：被分析的信号在 FFT 长度内是周期性的，或者测量的是周期性噪声信号。配合 REW 的周期性噪声信号时，一律要用矩形窗。

其他大多数信号，例如 REW 信号发生器产生的正弦波、CD 上的测试音或随机噪声，在 FFT 长度内通常都不是周期性的。用矩形窗分析这类测试音，会产生频谱泄漏（spectral leakage），频率细节很难分辨清楚。下图是外部信号发生器产生的 1 kHz 测试音，用矩形窗分析的结果。


下面是同一个测试音用 Hann（汉宁窗）分析的结果。


加窗后，测试音的各次谐波就能分辨出来了。但代价是，加窗会让被分析信号的频谱有一定程度的展宽，从而降低频率分辨率。

要在 REW 信号发生器上配合使用矩形窗，请勾选信号发生器的锁定 RTA FFT 频率选项。

汉宁窗适合大多数测量，在分辨率和旁瓣肩部高度（shoulder height）之间取得了较好的平衡。

如果要分辨很大的动态范围（dynamic range），也就是在很强的信号旁边分辨出很弱的信号，请用 4 项或 7 项 Blackman-Harris（布莱克曼-哈里斯窗）。

如果必须准确测出频谱峰值的幅度，请用 Flat Top（平顶窗）。无论测试音落在 FFT 区间的什么位置，平顶窗的幅度精度都能达到 0.01 dB。其他窗只有在测试音正好落在某个 FFT 区间中心时，才能准确显示频谱幅度。测试音落在两个区间之间时，显示的幅度会偏低，正好落在两个区间正中间时误差最大。这个最大误差，矩形窗是 3.92 dB，汉宁窗是 1.42 dB，4 项 Blackman-Harris 窗是 0.83 dB，7 项 Blackman-Harris 窗是 0.4 dB。

最大重叠率

频谱 / RTA 图可以每采集到一块输入音频数据就更新一次。每次分析取一段所选 FFT 长度的数据，相邻两段相互重叠。FFT 长度较大时，这会给处理器带来相当大的负担。用这个控件限制允许的最大重叠，可以减轻处理器负担。

停止信号发生器

勾选 RTA 停止时停止信号生成后，RTA 停止采集时，信号发生器也会随之停止。这个选项可以和停止于配合使用：平均次数够了，就自动关掉信号发生器。

信号发生器设置变化

勾选信号变化时重新捕获后，使用 RTA 期间，如果启动了信号发生器，或者在信号发生器运行时改了它的设置，RTA 会重新开始采集。

从信号发生器获取基频

勾选从信号发生器获取基频后，如果信号发生器正在播放正弦音，基波频率就取自信号发生器；否则，由输入信号里最大的峰值确定。

从信号发生器获取基波频率，能保证准确定出各次谐波的频率，即使严重失真让基波的频谱变得不对称也是如此。如果用外部陷波滤波器（notch filter）滤掉基波，也必须勾选这一项。

另一方面，如果系统的 DAC 和 ADC 用的是不同的时钟源（例如它们是两台不同的设备），接收到的频率（以 ADC 时钟为准）可能与发出的频率（以 DAC 时钟为准）相差较多，导致谐波识别错误，FFT 很长时尤其如此。这种情况下不要勾选这一项，RTA 也会显示警告。

失真设置


失真高通与失真低通

失真高通和失真低通用来设定参与失真计算的最低频率和最高频率。受它们影响的有三项：总谐波失真（THD）、总谐波失真加噪声（THD+N），以及双音、三音和多音信号的总失真加噪声（TD+N）。

失真高通和失真低通分别在勾选启用失真高通滤波、启用失真低通滤波后才生效，两者可以单独启用。启用后，图上不参与计算的区域会显示为灰色，THD、THD+N 和 TD+N 数值旁也会注明计算所用的频率范围。

手动基波

用陷波滤波器衰减基波时，可以手动填入一个基波电平，供谐波失真（harmonic distortion）计算使用。电平单位是 Vrms，并且要把陷波滤波器之后引入的增益考虑进去。这样 REW 计算失真时，用的才是正确的基波电平。

陷波滤波器也会改变各次谐波的电平。要补偿这一点，可以把陷波滤波器的响应作为校准文件载入。例如，先接入陷波滤波器，对回环连接做一次扫频测量；再去掉陷波滤波器，测一次。然后用 All SPL 图表的曲线运算功能，算出（有陷波的响应）/（无陷波的响应），把结果导出为文本文件，作为麦克风校准文件载入。

另一种做法是只测陷波滤波器的响应，再给这条测量加一个偏移，让它的 dB 值正确反映陷波滤波器在各次谐波处的损耗。基波处的数值不要紧，手动基波会处理它。然后把加了偏移的陷波响应导出为文本，作为麦克风校准文件载入。

这样，各次谐波的电平就会按滤波器的衰减得到修正。陷波滤波器的中心频率会有漂移，所以图表曲线上显示的基波电平通常有误差；但勾选了手动基波后，REW 不会使用这些数值。

失真显示单位

失真比可以按所选项显示为百分比或 dB。

谐波数据

THD 最高谐波设置决定哪些谐波计入 THD 数值。失真面板上的 THD 数值会注明计入了哪几次谐波。请注意，这项设置只影响 THD，不影响 THD+N。

勾选显示谐波至后，失真面板会显示各次谐波的电平，最高显示到旁边数值框里的次数。勾选显示谐波相位后，失真面板还会显示每次谐波相对于基波的相位。勾选显示高次谐波失真后，会多显示一个高次谐波失真数值，统计范围从 10 次谐波起，到测量带宽内最高的一次为止，最高到 50 次。


相干平均

这个选项只适用于谐波失真测量，而且只在采集单个输入时有效。勾选后，求平均之前，REW 先按基波的相位把 FFT 数据做相位对齐。与幅度平均（magnitude averaging）相比，这样能大幅降低本底噪声（noise floor），而且不需要很长的 FFT。实际上，较短的 FFT（例如 64k）平均得更快，本底噪声也降得更快。平均次数每加倍一次，噪声电平约下降 3 dB。

市电频率（工频）成分会被抑制，与基波没有谐波关系的其他噪声也会一并被抑制。所以这个选项只适合用来查看谐波电平。

请注意，如果谐波电平本身在变化，相干平均会收敛到它们的平均电平，幅度平均则会收敛到它们的 RMS 电平。失真面板里与噪声有关的各项数值（THD+N、N、N+D）仍按幅度平均的数据计算，依然有效。



互相关平均

这个选项只适用于谐波失真测量，而且要求同一个信号同时送入测量输入和回环参考输入。REW 对两个输入做互相关（cross correlation），再对结果求平均，以此降低输入级本身带来的噪声。

对互不相关的噪声，名义上的降低量是 5×log10(平均次数) dB：100 次平均可以把不相关的输入噪声降低 10 dB，10,000 次平均降低 20 dB。但两个输入共有的噪声成分降不下来，所以本底噪声的总体降幅可能小得多。

默认情况下，图上画的是互相关结果的实部，因为虚部来自输入噪声，而不是信号。但这样画出的曲线会出现一些尖刺，一直向下延伸到最低绘图电平（约 -240 dBFS）。另一种做法是勾选使用互相关幅度，画出复数结果的幅度，这个幅度把虚部也算在内。这样曲线更干净，但要更久才能收敛到不含输入噪声的噪声电平。

如果能给其中一个输入送入反相的信号，就可以勾选反相参考信号，把共模噪声（common mode noise）抵消掉。

请注意，使用互相关平均时，得不到谐波相位信息。

其他失真设置

勾选监控时钟同步后，使用多音测试信号或锁定 FFT 频率的正弦信号时，REW 会检查回放时钟与录音时钟的频率是否有差异。如果两者不一致，REW 会发出警告，提示不应使用矩形窗。如果两者一致、而当前用的不是矩形窗，REW 会建议改用矩形窗，以得到最准确的结果。

勾选高亮基波后，图上会高亮显示响应中算作基波的那一段，THD 和 THD+N 就按这一段计算基波功率。高亮区域以外的响应，用于计算噪声和噪声加失真。

勾选使用 AES17-2015 标准陷波后，THD 和 THD+N 计算所用的基波功率，取基波频率周围 1 倍频程范围内的功率。不勾选时，取基波主瓣（main lobe）内的功率。

如果基波电平没有明显高出本底噪声，用标准陷波算出的基波功率，会比用基波主瓣算出的高。这种情况下，最好不要启用标准陷波设置。

勾选应用 ENOB 幅度校正后，有效位数（effective number of bits，ENOB）会按输入的满量程电平做归一化，这样输入信号低于满量程时，显示的结果也有效。要得到能代表音频接口输入性能的数值，应勾选这一项。

外观设置


更新间隔

默认情况下，每从输入采集到一块音频数据，频谱 / RTA 图就更新一次。这会给处理器带来相当大的负担，RTA 窗口很大或 FFT 长度很大时尤其如此。

降低图的更新频率，可以减轻处理器负担，具体用更新间隔控件设定。更新间隔为 1 时，每块数据都重绘一次曲线；设为 4 时，每 4 块数据才更新一次曲线，依此类推。

峰值保持与峰值衰减

峰值保持和峰值衰减两个控件，分别设定峰值保持多长时间（单位秒），以及峰值衰减得多快（单位 dB/秒）。峰值保持设为 0 时，峰值完全不保持；峰值衰减设为 0 时，峰值曲线不衰减。

显示噪声曲线

勾选显示噪声曲线后，在采集单个输入、RTA 处于 1 倍频程模式且 Y 轴以 dB 显示时，图上会画出所选的噪声曲线。可选的有：优选噪声准则（Preferred Noise Criterion，PNC）、平衡噪声准则（Balanced Noise Criterion，NCB）、噪声准则（NC）和噪声评价数（NR）。

请注意，如果勾选了调整 RTA 电平，这些曲线会与 RTA 曲线偏移同样的量，但噪声准则的评定结果不会因此改变。


CEA2010 最大 SPL 限值

使用 CEA2010 猝发测试信号时，失真加噪声的阈值可以选用以下三种标准之一：CEA 2010-2006；ANSI/CTA-2010-B R-2020 Standard Method of Measurement for Powered Subwoofers（有源低音炮测量标准方法）；ANSI/CTA-2034-A Standard Method of Measurement for In-Home Loudspeakers（家用音箱测量标准方法）。

按标准规定，REW 根据基波频率选定对应的频带，阈值叠加线的颜色就表示选中的是哪个频带。

线条或横条

在频谱模式或 RTA 模式下，图上可以在各 FFT 区间的中心点之间连线，也可以画成横条，横条的宽度等于 FFT 区间宽度或 RTA 分数倍频程宽度。具体由频谱以横条显示和 RTA 以横条显示两个勾选框控制。

RTA 填充

在 RTA 模式下，勾选填充 RTA 区域后，图会填充颜色。

调整 RTA 电平

RTA 图显示的是每个分数倍频程带宽内的能量。RTA 分辨率从 1 倍频程提高到 1/48 倍频程时，分数倍频程带宽随之变窄。对粉红噪声这类宽带测试信号，每个分数倍频程内的能量也相应减少。

RTA 显示的确实是每个分数倍频程内的实际电平。但曲线电平随 RTA 分辨率而变，用 RTA 配合粉红 PN（粉红周期噪声）信号调整音箱位置或均衡器设置时，就不太方便。

调整 RTA 电平选项会给 RTA 图上显示的电平加一个偏移，补偿两方面的差异：一是改变分辨率时带宽的变化；二是在同一电平下，扫频测量与全频段粉红 PN 的 RTA 测量在显示电平上的差别。这样，RTA 图与扫频图就能直接比较。显示的电平虽然不是各分数倍频程内真实的声压级，但用起来更方便。

注意：这个选项只应配合宽带测试信号使用，例如粉红噪声或粉红 PN。

使用 64 位 FFT

勾选这一项后，RTA 用 64 位 FFT 处理输入数据，而不是 32 位。分析纯数字的 24 位数据通路、要看 -160 dBFS 以下的表现时，这一项很有用。如果数据通路上任何一处有模拟连接，或者处理的是 16 位数据，这一项不会带来看得出的变化：这些情况下，噪声和量化（quantisation）效应远远超过 32 位运算的数值精度限制。

下面几张图是示例。REW 信号发生器产生 -20 dBFS 的 1 kHz 正弦波，经 S/PDIF 回环连接传输 24 位数据，在未加抖动和加抖动两种情况下，分别对比 32 位 FFT 与 64 位 FFT 的差别。纵向网格每格 20 dB，图底部为 -220 dBFS。





显示猝发音峰值 SPL

勾选这一项后，如果信号发生器正在播放猝发音（tone burst），图表又处于频谱模式，图上会显示输入数据中的峰值 SPL。这与 CEA-2010 的峰值 SPL 类似，只是没有在基波频率周围做 1/3 倍频程滤波。

显示听力 SPL 阈值

勾选这一项且 Y 轴为 SPL 时，图上会叠加一条曲线，显示 18 至 25 岁听力正常人群的听阈（hearing threshold）声压级。这条听阈对应的条件是：自由场、纯音、声音从正前方入射。

寻峰器

点击寻峰器按钮，会弹出一个对话框，用来找出频谱中的峰值，并列成表格。


最低频率和最高频率两个控件，设定在哪个频率范围内找峰值。最低电平设定峰值至少要达到多少 dBFS，才列入表格。

突出度（prominence）衡量一个峰值比频谱基线高出多少，等于峰值电平减去它的基底。峰值的基底（也叫最低等高线，lowest contour line）取左基底和右基底中较高的一个。左、右基底的求法是：从峰值出发分别向左、向右走，直到频谱的端点或遇到一个更高的峰值为止，途中遇到的最低电平就是这一侧的基底。

点击查找峰值按钮，REW 会对当前频谱数据做一次快照，在快照里查找峰值。峰值列表默认按电平排序；点击任意列标题，可以改按该列排序。找到峰值后，还可以调整频率、音名、电平和突出度的限值，筛选列表。

曲线选项

点击曲线选项按钮，会弹出一个对话框，可以修改图表曲线的颜色和线型。如果修改的是测量曲线，修改会应用到这张图上显示的所有测量，覆盖各测量自己的颜色。曲线也可以隐藏，隐藏后会从图上和图例（legend）中移除。

失真测量

按下显示失真值按钮（快捷键 Alt+D）后，分析仪会计算并显示输入信号的谐波失真或互调失真数值，包括：THD；N+D（A 计权的噪声加失真）；N（噪声加非谐波失真，non-harmonic distortion）；THD+N；信噪比（signal-to-noise ratio，SNR；这里的 N 不含谐波失真）；ENOB；HHD（高次谐波失真，统计 10 次起、最多到 50 次的谐波）；以及 2～9 次谐波各自的相对电平。

N 和 N+D 以当前 Y 轴单位显示。谐波失真按失真设置里的选择，显示为相对于基波的百分比或 dB。

做多通道 RTA 测量时，如果只选了两个输入，失真数值会按输入分别显示。

谐波失真

只有被测系统由单一频率的测试音或猝发音驱动时，谐波失真结果才有效。以下两种情况，以信号发生器的频率作为输入的基波频率：一是 REW 信号发生器正在播放正弦信号，并且勾选了从信号发生器获取基频；二是信号发生器正在播放猝发音。其他情况下，由最高的峰值确定基波。

面板上会显示基波频率和基波电平；信号发生器播放正弦信号时，还会显示电压增益。如果在失真设置里勾选了使用 AES17-2015 标准陷波，基波数值取基波频率周围 1 倍频程范围内的功率；不勾选时，取基波主瓣内的功率。

激励信号是猝发音时，猝发音的包络（envelope）会让频谱明显展宽。因此只有失真比较高时才测得出来，具体能测到多低，取决于包络形状。失真计算使用离基波频率和各谐波频率各自最近的那个 FFT 区间的电平。与噪声有关的结果不做计算，因为算出来也没有意义。

对连续测试音计算基波和各谐波的功率时，REW 先把各标称频率附近一定范围内的 FFT 区间能量相加（范围大小取决于 RTA 所选的窗函数），再按该窗函数的等效噪声带宽（equivalent noise bandwidth）做修正。要得到准确的结果，窗函数的旁瓣（side lobe）要低。

按旁瓣电平从高到低，较好的选择依次是：Dolph-Chebyshev 150（道尔夫-切比雪夫窗，旁瓣低 150 dB）、Blackman-Harris 7（旁瓣低 180 dB）、Dolph-Chebyshev 200（旁瓣低 200 dB）和 Cosine sum 9-235（余弦和窗，旁瓣低 235 dB）。不推荐用 Hann、Blackman-Harris 4 和 Flat-Top。

使用 REW 信号发生器时，勾选它的“锁定 RTA FFT 频率”选项，就可以使用矩形窗。

信号发生器应启用抖动，抖动的位数要与系统实际使用的位数一致；系统使用的位数显示在 REW 主窗口左下角。在 Windows 上使用 Java 驱动时只支持 16 位，要用 24 位请改用 ASIO 驱动。macOS 支持 24 位，请在“音频 MIDI 设置”里确认设备配置为 24 位或更高。

THD 数值计入的谐波最多到 50 次，或者只计入面板上显示了电平的那几次。计算方法是把这些谐波的功率相加，再与基波功率相比。另有一个单独的 HHD（高次谐波失真，higher harmonic distortion）数值，由 10 次起、最多到 50 次的谐波功率之和算出。THD 数值里包含 HHD 这部分。各次谐波各自的数值，同样是该次谐波的功率与基波功率之比。

THD+N 数值等于“输入总功率减去基波功率”与“输入总功率”之比（注意，按这样的定义，THD+N 有可能比 THD 还低）。THD+N 的倒数就是信纳比（SINAD）。

N 数值由 THD+N 减去 THD 得出，这里的 THD 计入失真带宽内的全部谐波。Y 轴单位为 dBc 时，N 表示为相对于输入总功率的比值；Y 轴为其他单位时，表示为绝对数值。

失真计算所用数据的上限，是奈奎斯特频率（Nyquist frequency，即采样率的一半）的 95%；如果启用了失真低通，则以失真低通为上限。下限是第一个 FFT 区间（不含直流）；如果启用了失真高通，则以失真高通为下限。

下面的例子是 1 kHz 正弦输入的数据。频谱图或 RTA 图上会标出各次谐波的位置。这里失真高通和失真低通分别设为 20 Hz 和 20 kHz，所以结果基于 20 Hz 至 20 kHz 范围内的数据。


THD 数据旁边还会显示一个 A 计权的噪声加失真（N+D）数值，单位是当前 Y 轴单位。把这个数值与最大输入电平（指失真仍优于 -40 dB 时能达到的最高输入电平）结合起来，就能得出动态范围。要按 AES17-2015 得到有意义的 N+D 结果，应该用 997 Hz 正弦波驱动系统，电平比最大输入电平低 60 dB。

互调失真

只有被测系统由 REW 的双音测试信号驱动时，互调失真结果才有效。这个信号可以由信号发生器实时产生，也可以保存为文件，在被测系统上回放。从文件回放时，信号发生器窗口仍要开着并选中同一个信号，REW 才知道该计算什么。

信号发生器提供 SMPTE、DIN、CCIF 和 AES17-2015 几种互调测量信号的预设，另有一个“自定义”选项，可以自选一对频率，幅度比为 1:1 或 4:1。

幅度比 1:1 的信号从 -3.0 dBFS 开始削波。这是勾选了设置 → 视图里满量程正弦波 RMS 为 0 dBFS 时的数值；不勾选时，削波电平还要再低 3 dB。幅度比 4:1 的信号在 -1.8 dBFS 削波。幅度比为 4:1 的自定义信号，REW 默认按调制失真（modulation distortion）测量处理。

信号发生器应启用抖动，抖动的位数要与系统实际使用的位数一致；系统使用的位数显示在 REW 主窗口左下角。在 Windows 上使用 Java 驱动时只支持 16 位，要用 24 位请改用 ASIO 驱动。macOS 支持 24 位，请在“音频 MIDI 设置”里确认设备配置为 24 位。

要得到准确的结果，RTA 窗函数的旁瓣要非常低。按旁瓣电平从高到低，较好的选择依次是：Dolph-Chebyshev 150（旁瓣低 150 dB）、Blackman-Harris 7（旁瓣低 180 dB）、Dolph-Chebyshev 200（旁瓣低 200 dB）和 Cosine sum 9-235（旁瓣低 235 dB）。不要使用 Hann、Blackman-Harris 4 或 Flat-Top 窗。



CCIF 数值由 f2 - f1 处的电平算出，这一项也叫二阶差频失真（Difference Frequency Distortion，DFD），记作 DFD2。同时还显示三阶的 DFD3 数值，它基于 2*f1 - f2（18 kHz）和 2*f2 - f1（21 kHz）处的电平。DFD 数值的参考电平，是 f1 处电平与 f2 处电平之和。

另外还显示一个 IMDpwr 数值，它是两个 RMS 和之比：分子是各互调成分的 RMS 和，分母是 f1、f2 和各互调成分合在一起的 RMS 和。

TDFD 的 IMDTDFD 由二阶和三阶成分的 RMS 和算出，百分比数值的参考电平是 f1 与 f2 处电平之和。TDFD Phono 和 TDFD akl 用 d2L（f2 - f1）和 d3L（2*f1 - f2）；TDFD Bass 用 d2H（f2 + f1）和 d3H（2*f2 - f1）。

AES17 DFD 的 IMDAES 数值基于 f2 - f1（2 kHz）、2*f1 - f2（16 kHz）和 2*f2 - f1（22 kHz）处的电平，IMDAES 百分比数值的参考电平是 f1（18 kHz）处的电平。按 AES17-2015 规范，这些电平都在以被测成分为中心的 500 Hz 带宽内测量。同时也显示 DFD2 和 DFD3。

AES17 MD 的 IMDAES 由二阶（d2）成分的 RMS 和算出，百分比数值的参考电平是 f2 处的电平。REW 显示总的 IMD 数值，以及合并后的二阶（MD2 = d2L + d2H）和三阶（MD3 = d3L + d3H）数值。

对 AES17 MD 以外的信号（包括 SMPTE 和 DIN），IMDDIN 数值由二阶（d2）和三阶（d3）成分的 RMS 和算出，百分比数值的参考电平是 f2 处的电平。REW 显示总的 IMD 数值，以及合并后的二阶（MD2 = d2L + d2H）和三阶（MD3 = d3L + d3H）数值。

请注意，过去 SMPTE 和 DIN 互调失真是用模拟的幅度解调（amplitude demodulation）方法测量的，结果里包含了解调通带内的噪声。用 FFT 分析，可以像上面那样直接测出并使用各个互调成分，减少噪声的影响。这种方法也称为调制互调失真（Modulation IMD，MOD IMD）。

无论哪种信号，REW 都会显示一个总失真加噪声百分比 TD+N。它的算法是：用噪声和失真的总功率除以各测试音的总功率，再开平方根。

多音总失真

被测系统由 REW 的多音测试信号驱动时，RTA 会显示一个总失真加噪声 TD+N 数值。它的算法是：用噪声和失真成分的总功率除以各测试音的总功率，再开平方根。

要得到最准确的结果，信号发生器与信号采集应使用同一个时钟源：两者经过同一台设备，或者经过采样时钟相互同步的几台设备。同时应使用矩形窗。

勾选了失真设置里的监控时钟同步后，REW 会在采集信号的同时测量回放时钟与录音时钟的差异。使用矩形窗时，时钟差异以 ppm 数值显示在失真结果下方。如果这个数值最终没有稳定在 0.0 ppm，说明两个时钟没有同步，必须改用矩形窗以外的窗函数，例如 Blackman-Harris 7。用非矩形窗时，可能需要更长的 FFT，才能分辨测试信号里的低频测试音。如果当前不是矩形窗、而时钟频率一致，REW 会建议改用矩形窗，以得到最准确的结果。

如果使用矩形窗，并且 FFT 长度至少是信号长度的两倍，还会显示一个信噪比数值。这时各测试音只会落在序号为（FFT 长度/信号长度）整数倍的区间里，其他区间里的成分就都是噪声。

噪声数值的求法是：先对这些噪声区间做 RMS 求和，再按被排除区间（即测试音所在的区间）所占的比例换算。SNR 是输入的总 RMS 电平与这个不计权噪声电平之比。


保存多音测量后，失真图上会显示基波电平（按各测试音的电平算出）、本底噪声和 TD+N 的曲线。只有同时满足以下条件，才有本底噪声数值：使用矩形窗，信号发生器与采集使用同一个时钟，FFT 长度至少是信号长度的两倍。

步进正弦失真

按下步进正弦按钮，会弹出一个对话框，用来配置并运行步进正弦（stepped sine）失真测量。测量可以按电平步进、按频率步进，或者两者同时步进（仅限 THD）；测的可以是谐波失真、互调失真或多音失真。


做多通道 RTA 测量时，如果只选了两个输入，可以对这两个输入同时做步进正弦测量。

测量信号由 REW 的信号发生器产生。请注意，测量使用信号发生器当前的设置，所以只有勾选了抖动才会加抖动（默认勾选，也推荐勾选）。

频率可以在所选范围内按每倍频程 1 至 96 点的间隔步进；电平步长最小可到 0.1 dBFS。做“THD vs 频率”测试时，标称测试频率取所选测量 PPO 下的优选频率值（preferred values），只取落在测量范围内的那些。为了避免扇贝损失（scalloping loss），实际测试频率取最接近的 FFT 区间频率，这样能保证基波和全部谐波的峰值都被准确记录到图上。

每一步都会采集全部失真数据；所有点采集完后，生成一条新的测量。THD 测试进行中，RTA 图上会显示基波（棕色）、二次谐波（红色）、三次谐波（橙色）和 THD 的电平，第一个输入用实线，第二个输入用虚线。IMD 测试显示参考电平（视激励信号而定，是 f1 的电平，或 f1 与 f2 电平之和）以及 IMD 和 TD+N 电平。多音测试显示参考电平（多音信号的电平）和 TD+N 电平。

按停止按钮，会用截至当时采集到的数据生成测量。步进正弦测量通常要好几分钟。暂停按钮暂停测量并关闭信号发生器，再按一次继续测量。返回按钮删除最后测得的那个点，并重新测这一点；测量运行中或暂停时都可以用返回。取消放弃这次测量。

按频率步进时，如果勾选了每步捕获频谱，每一步都会记录一份频谱数据副本，按对数间隔、每倍频程 96 点。这些频谱数据可以在瀑布图或频谱图上查看，也可以导出为文本文件。

请注意，不要用导出的频谱数据去计算失真电平：它的频率分辨率不够，算不准每次谐波里的能量。

如果测量链路里有些部件在激励变化后需要额外的时间才能稳定，可以指定一个稳定时间，单位毫秒。每种测试类型有各自的稳定时间设置。还可以指定一个静音间隔，单位秒，让被测设备在两个测试点之间有时间冷却。

失真低通、失真高通、AES17-2015 标准陷波和相干平均这几项失真设置，为方便起见，在这个对话框里也重复列出。

勾选输入严重削波时停止后，如果一个输入数据块里超过 30% 的采样被削波，测量就会停止。这大约相当于输入电平比削波阈值高 2 dB。

勾选失真阈值停止后，如果失真超过所填的限值，测量就会停止。这项检查要等失真先降到限值以下才开始生效。这样，按电平步进的测量就可以从低电平开始：信号电平很低时，失真数值可能单纯因为噪声而偏高。采集多个输入时，只对第一个输入做失真检查。

按电平步进的测量还多一个选项：失真超限时尝试较小步进。勾选后，失真一旦超限，测量会暂停，退回上一步，再用较小的步长继续，直到试过最小步长（0.1 dB）为止。这样不必整个测量都用小步长，也能更准确地找出失真达到限值时的电平。

按频率步进时，最低起始频率取决于 FFT 长度和采样率。例如 8192 点 FFT、44.1 kHz 采样率时，最低起始频率约为 60 Hz；32768 点 FFT、44.1 kHz 时，约为 15 Hz。低于这个最低频率时，RTA 窗函数的展宽效应会掩盖二次谐波的电平，得不到有效的失真读数。

测量频率都选在所选 FFT 长度对应的区间频率上，这样窗函数的扇贝损失就不会影响基波或谐波的幅度。

每次测量开始时，REW 会先采集本底噪声，用来掩蔽低于本底噪声的失真结果（可选，见失真图帮助）。

进度条显示完成测量大约还需多少时间。使用 ASIO 驱动时，步进正弦测量更快：ASIO 的输入和输出缓冲区比 Java 驱动小，改变频率或电平时，缓冲区排空所需的时间更短。失真结果可以在失真图上查看。

如果勾选了设置 → 分析里的校准文件应用于失真分析，结果会包含按校准文件响应所做的修正（RTA 的失真数值也是这样处理的）。在基波或谐波受音频接口滚降（roll-off）影响的频段，应用校准文件能得到更准确的结果，但同时也会抬高这些频段的本底噪声。查看结果时要考虑到这一点。

如果需要较大的校准修正量，请确认设置 → 分析里的将校准数据增益限制为 20 dB 没有勾选。

步进正弦测量虽然比对数扫频（log sweep）慢得多，但它能测出 N（噪声加非谐波失真）以及 THD+N 或 TD+N，这几项用对数扫频都测不出。它测低失真也比扫频更准确，在高频段和高次谐波上尤其如此。所以它很适合测量电子设备的失真。

下面几张图是一次声卡回环测量，电平为 -12 dBFS，分别用步进正弦（64k FFT，24 ppo）和 1M 对数扫频重复 8 次测得。注意用扫频测量时，谐波电平随频率升高而上升。这反映的是设备的本底噪声随频率升高而上升（在 RTA 窗口的 RTA 模式下可以看到）。扫频把失真和噪声分开的能力，不如步进正弦测量。
