失真图


失真图显示测量的基波（fundamental），也就是响应中的线性部分。除此之外，它显示哪些失真数据，取决于所显示数据来自哪种测量：有的显示最高到九次谐波的各次谐波失真（harmonic distortion）分量，以及总谐波失真（Total Harmonic Distortion，THD）；有的显示总失真加噪声（total distortion plus noise，TD+N）等其他失真指标。

如果测量时采集了本底噪声（noise floor），图上还可以显示本底噪声的电平。

谐波曲线只能在测量带宽以内生成。例如，测量上限为 20 kHz 时，二次谐波曲线最高只能生成到 10 kHz，因为 10 kHz 的二次谐波就是 20 kHz。同理，三次谐波曲线最高只能生成到 6.67 kHz（20/3）。

失真曲线的频率上限是奈奎斯特频率（Nyquist frequency，即采样率的一半）的 95%。例如采样率为 44.1 kHz 时，上限是 0.95*44.1/2 = 20.95 kHz。

总谐波失真由现有的各次谐波计算得出。有一个控件用来选择计算 THD 时用到的最高次谐波；图例里的曲线名会标明计入了哪几次谐波。频率越高，能取得的谐波越少，THD 曲线计入的谐波也随之减少。

如果勾选了设置 → 分析里的校准文件应用于失真分析，失真结果会包含按校准文件响应所做的修正（RTA 的失真数值也是这样处理的）。

在基波或谐波受音频接口滚降（roll-off）影响的频段，应用校准文件能得到更准确的结果，但同时也会抬高这些频段的本底噪声。查看结果时要考虑到这一点。

如果需要较大的校准修正量，请确认设置 → 分析里的将校准数据增益限制为 20 dB 没有勾选。

请注意：之后再修改校准文件，不会更新已有的失真结果。失真结果是用测量当时所用的校准文件生成的。

失真数据可以用文件 → 导出 → 将失真数据导出为文本导出为文本文件。

扫频测量的失真

用对数扫频（logarithmic sweep）测得的脉冲响应，会把谐波失真与系统响应的线性部分分开。各失真分量出现在负时间处，也就是主脉冲的左侧。分析这些分量的频率成分，就能画出各次谐波失真曲线。

扫频越长，各失真分量彼此分得越开，也分辨得越清楚。由扫频测量得出的基波与谐波曲线，使用频率相关时间窗（frequency-dependent window）来压低噪声，其平滑效果大致相当于 1/48 倍频程。

256k 及更短的扫频应从 0 Hz 开始。否则得到的脉冲响应低频带宽不足，会让最低频段的失真出现人为的升高。

测量失真较大的系统时，要用长扫频（例如 1M 或更长）。扫频较短时，各次谐波可能相互影响，给出误导性的结果。

对关心的频率，可以用 RTA 和信号发生器做一下抽查。如果用了长扫频，结果仍与抽查对不上，可以考虑改做步进正弦测量（stepped sine measurement）。

扫频测量想要尽量低的本底噪声，可以用多次扫频，但这要求输入和输出在同一个设备上。

失真曲线的频率下限取 10 Hz 与测量起始频率中较高的一个。10 Hz 是测量扫频中对数部分的下限。起始频率低于 10 Hz 时，扫频开头会先扫一段线性部分（以免在极低频上花掉过多扫频时间），这一段不能用来生成失真数据。

另外请注意：起始频率为 20 Hz 或更高的扫频，低频段的失真可能显得逐渐升高。原因是带限（band limited）脉冲响应本身带有时域振铃（ringing），振铃与失真谐波重叠在了一起。要避免这种情况，尽量把起始频率设在 20 Hz 以下，并使用更长的扫频。

对带失真数据的测量做平均时，只要这些测量的频率范围和分辨率都相同，它们的失真数据也会一起平均。

步进正弦测量的失真

步进正弦测量比对数扫频慢得多，但测量极低的失真时，可能比扫频更准确。

与扫频得出的结果一样，步进正弦失真测量会显示最高到九次谐波的各失真分量、THD 和本底噪声。此外，它还给出 THD+N（总谐波失真加噪声及非谐波失真）和单独的 N（噪声及非谐波失真）。

请注意：本底噪声曲线显示的是不播放信号时测得的噪声频谱。而 N 和 THD+N 中的“噪声”是总和电平：对每个测试频率，它把整个频率范围内的所有非谐波失真与噪声加在一起。所以它比本底噪声曲线高得多。

对步进电平测量，X 轴可以是 dB SPL、dBFS、dBu、dBV、dBW、V 或 W，显示的是发生器电平或输入电平。对“IMD vs 电平”步进测量，“输入”指 IMD 信号中参考音的电平（例如 SMPTE IMD 中 f2 的电平），而不是输入的总 RMS 电平。

失真图的图表选项

这张图表的图表选项面板上有以下控件：


默认情况下，图上显示基波和各次谐波的绝对电平。Y 轴单位可以设为 dB SPL、dBFS、dBu、dBV、dBW、volts、watts、dBr 或 percent。dBW 和 watts 的数值由测得的电压换算而来，换算时用的是 RTA 外观设置里的 dBW 参考阻抗。

Y 轴设为 percent 或 dBr 时，各次谐波都除以基波，显示的是相对电平；基波本身则变成一条位于 0 dBr 或 100% 的水平直线。图例里基波的读数仍显示绝对电平，谐波和 THD 的读数则取决于失真数值的设置。

被测系统的响应在高频滚降时（通常都是这样），归一化（normalise）后的失真曲线会在高频段往上翘。如果勾选了以谐波频率为参考（见下文），上翘会更明显。

基波电平低造成的这种抬升，可以勾选归一化下限设为峰值以下 30 dB 来控制。它给基波设一个下限，比基波峰值低 30 dB。例如基波峰值为 95 dB 时，归一化用到的基波电平最低就是 65 dB。

归一化模式下，谐波和 THD 曲线默认以每个频率上的基波电平作参考。例如，1 kHz 处各次谐波的失真数值，取决于 1 kHz 处的基波电平。

如果勾选以谐波频率为参考，参考点就改为谐波所在的频率。例如在 1 kHz 处，二次谐波的数值取决于 2 kHz 处的基波电平，三次谐波取决于 3 kHz 处的基波电平，依此类推。这一做法来自 Steve F. Temme 在 1993 年 3 月第 94 届 AES 大会上发表的论文“How to graph distortion measurements”（《如何绘制失真测量结果》）中的建议。

被测系统的响应平直时，两种参考方式的结果没有区别。响应不平直时（大多数声学测量都是这样），以谐波频率为参考，可以把音箱基波响应的影响从失真数值中去掉。

举个例子：假设音箱响应除了 2 kHz 处有一个 6 dB 的峰以外都是平直的。2 kHz 是 1 kHz 的二次谐波，所以以激励频率（excitation frequency）为参考时，1 kHz 处显示的二次谐波电平会因为 2 kHz 处的这个峰而高出 6 dB。同理，667 Hz（2/3 kHz）处的三次谐波电平也会高出 6 dB。如果以谐波频率为参考，失真数值就不会出现这种抬升。

以谐波频率为参考，还能让系统低频滚降点以下的失真显示得更有意义；否则，随着基波电平下降，失真电平会被抬高。

请注意：图表未归一化时，这个选项不影响曲线；但如果失真数值设为以百分比或相对基波的 dB 显示，它仍会影响图例里的数值。

遮罩低于本底噪声的谐波会把低于本底噪声的谐波变成灰色，这里的本底噪声按谐波所在频率处的数值算。如果计入 THD 的各次谐波全都低于本底噪声，THD 曲线也会变灰。

谐波频率处绘制谐波改变扫频测量各次谐波失真的绘制方式：失真不再画在基波频率上，而是画在谐波所在的频率上。例如，1 kHz 的二次谐波失真电平会画在 2 kHz 处，也就是失真实际出现的频率上。

这样更容易把谐波电平与谐波频率处的基波电平对照着看。它也有助于分辨外部噪声的影响，因为噪声出现在哪个频率，就会在那个频率上同时影响所有各次谐波。

THD 曲线不受这个选项影响，仍显示各次谐波在其基波频率处对应的 THD 值。不过，按谐波频率绘制时，参考电平取谐波频率处的基波电平；在这种图表模式下，谐波频率就是光标（cursor）所在的频率。所以以谐波频率为参考会被自动勾选，并且变为不可用。如果之前没有勾选以谐波频率为参考，THD 曲线会随之更新。

失真数值用来选择图例中谐波失真电平的显示单位，有三个选项：

As Y axis（与 Y 轴相同）：用当前 Y 轴的单位显示电平；dB relative（相对 dB）：显示谐波比基波低多少 dB；Percent（百分比）：把谐波电平显示为基波的百分比。

基波电平取自哪个频率，取决于以谐波频率为参考的设置（见上文）。

要显示的最高谐波用来隐藏不关心的高次谐波。例如把要显示的最高谐波设为 3，图上和图例里就只出现二次和三次谐波曲线。计算 THD 时用到哪些实测谐波，则由 THD 中的最高谐波决定。

THD 中的最高谐波用来在计算 THD 时排除较高次的谐波。如果这些谐波已经落入本底噪声，把它们计入 THD 等于把噪声也算了进去，这时就需要排除它们。

勾选步进电平数据显示点后，图上会标出每一个数据点。

播放 FSAF 残差信号、增益、加载 FSAF 残差信号、保存 FSAF 残差信号和设置 FSAF 文件夹这几个控件用于 FSAF 测量。

曲线选项按钮会打开一个对话框，可以修改图表中各条曲线的颜色和线型。所做的修改会应用于这张图表上显示的所有测量。曲线也可以隐藏，隐藏后会从图表和图例中移除。

下面两张图是同一块声卡在 -2 dBFS 下的回环测量，分别用 4M 扫频（耗时 95 秒）和步进正弦（64k FFT、每倍频程 24 点（points per octave，ppo）、约 17 分钟）测得。4M 扫频的谐波曲线比上面 256k 扫频的干净得多；不过步进正弦结果的本底噪声，比 256k 和 4M 两次扫频都低约 6 dB。多次扫频可以降低本底噪声（前提是输入和输出在同一个设备上），但测量时间也会相应加长。

这块声卡有一个值得注意的特点：它的奇次谐波会随信号持续通过的时间长短而变化。上面的 256k 扫频中，三次谐波在 800 Hz 以上就超过了二次谐波。用 4M 扫频时，三次谐波要到 1.4 kHz 才超过二次谐波；这次 44.1 kHz、4M 测量的总扫频时间是 95 秒，而 256k 扫频只有 5.9 秒。步进正弦测量的差别更大，两条曲线要到 2.2 kHz 才交叉。

连续做一串扫频、中间不留间歇，扫频测量也能看到类似的现象。可见，设备此前通过了多长时间、什么样的信号，可能对它的失真有明显影响。

这次步进测量用了 17 分钟以上（每倍频程 24 点、64k FFT、2 次平均、50% 重叠）。耗时长主要有三个原因：频率改变时，（较大的）音频缓冲区需要时间清空；每次 FFT 都要采集足够的样本；而每倍频程 24 点的频率分辨率相对较高，在所测的 20 Hz 到 20 kHz 范围内共要测 240 个点。

失真示例：音箱测量

音箱测量的结果更难解读，尤其是在房间里测、而不是在消声室（anechoic chamber）里测的时候。

电子设备的失真结果通常用百分比表示，也就是相对基波的数值。但音箱的频率响应往往很不规则，把音箱测量的失真也画成百分比，结果就很难解读。以谐波频率为参考（见上文失真图的图表选项）能起一些作用，但远远不能彻底解决问题。

笔者个人更倾向于不做归一化，直接看失真结果。这样既能让响应不规则的影响一目了然，又能突出各失真分量的声学电平，有助于判断哪些失真可能听得到、哪些听不到。以 SPL 电平查看失真图时，仍然可以用失真数值控件，让图例读出失真百分比。

下面是一只小型桌面音箱（Adam Artist 3）的测量。麦克风（UMIK-1）离音箱只有 15 cm，所以测得的 SPL 比较高；换算到约 70 cm 外的听音位置，大约相当于 85 dB。





80 Hz 附近那一片奇次谐波的隆起，看起来是轻微削波。3 kHz 以上由音箱的带式高音单元（ribbon tweeter）接手，这一段的失真电平在扫频结果里已低于本底噪声，步进正弦则仍能稳定地测出来。

这是一次近场测量（near field measurement），房间的影响较小，但频率响应的起伏仍会让归一化后的图更难看懂。下面是归一化后的结果，没有以谐波频率为参考。图上还画出了本底噪声（深棕色），用来说明在响应凹陷处，归一化会把本底噪声抬高。


可以看出，3 kHz 附近二次谐波失真的那个峰，只是本底噪声被抬高的结果，可以忽略。不过，如果没有本底噪声曲线作参照，就不那么容易看出这一点。

另一方面，低频段的失真现在显示得比实际高得多。原因是音箱响应在低频滚降，归一化时用作参照的基波电平低得多。图上那 10% 的二次谐波乍看令人担心，但认清它只是归一化带来的伪像（artefact）之后，就不必在意了。

用谐波频率处的基波电平作归一化参考，可以减轻低频段的归一化伪像，得到的就是下面这张图，低频段的表现现在更准确了。不过，1 kHz 以上的二次、三次谐波又出现了新的峰，这是以 3 kHz 为中心的响应凹陷造成的。这个凹陷可能是因为测量位置离音箱太近，中低音单元与高音单元在分频点处衔接不好。这些失真峰多半不是真实存在的。

不做归一化的视图，最不容易被误读。
