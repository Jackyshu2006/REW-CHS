图表面板

图表面板（graph panel）显示当前选中测量的各种图表。要看哪一种，用图表区（graph area）顶部的按钮选择。

图表类型有以下几种：
SPL 与相位图
All SPL 图
失真图
脉冲响应图
滤波 IR 图
群延迟图
RT60 图
清晰度图
频谱衰减图
瀑布图
频谱图
采集信号图

影响曲线（trace）外观的选项，在设置 → 视图里。

在单个测量的图表上，每条曲线都可以用图例区（legend panel）里曲线名称左侧的勾选框单独显示或隐藏。

在叠加图（overlay graph，All SPL 图也属于叠加图）上，关闭一条曲线就等于在叠加图的测量列表里取消选中这条测量，曲线随之从图表上移除。

曲线名称的颜色与曲线本身相同。名称和该曲线在当前光标（cursor）位置的数值之间，画着这条曲线的线型。

如果曲线做过平滑处理（smoothing），这里会标出所用的倍频程分数（下图示例为 1/48 倍频程）。

把鼠标指针移到图例（legend）中某条曲线的名称上，图表上的这条曲线就会高亮，其他曲线变淡，让它更醒目。高亮时还可以同时显示测量名称，由设置 → 视图里的显示高亮曲线名称选项控制。

在叠加图上，可以按 Ctrl+H 高亮当前选中的那条测量，再按一次取消高亮。

在图表的图例区单击右键，会弹出一个小菜单，可以选中全部曲线、取消全部选择或反选。

另存图片按钮


图表区左上角的这个按钮，用来把当前图表画面保存为图片，快捷键是 Alt+C。

点击后会弹出一个对话框。先设置图片宽度（点默认按钮，图片就与图表等宽）。曲线粗细也可以选，REW 默认是 2 像素。另有一个下拉框用来选图片的配色方案，默认沿用 REW 当前的配色方案。勾选标题选项后，图片顶部会显示图表类型。

IEC 263 比例只适用于横轴为对数频率轴、纵轴为 dB 轴的图表。它会调整导出图片的高度，使频率轴上一个十倍频程（decade，如 20 Hz 到 200 Hz）的长度，等于 dB 轴上 10 dB、25 dB 或 50 dB 的跨度。这三档取自 IEC 263 标准给出的选项。

这样，频率响应图在视觉上就有统一的比例。曲线不会因为纵轴被拉伸或压缩而显得过分平坦，响应斜率也不会看起来比实际更缓或更陡。

导出的图片还有一组选项（在对话框的“选项”下拉框里勾选）。勾选图例，图片会包含图表的图例。勾选标题，图片会包含图表标题。勾选光标，图片上会画出光标线及其数值。勾选时间戳，图表右下角会显示当前日期和时间。勾选边框，图片四周会加一圈 1 像素宽的灰色边框。

勾选单色后，曲线不再用不同颜色区分，而是分别用四种线型之一绘制：实线、点线、虚线或点划线。

勾选缩放信息框后，如果为图片选定的图表字号与当前图表字号不同，图上叠加显示的信息框会按相应比例缩放。

注释可以放在图片上方、下方或图片上。放在上方或下方时，可以选左对齐、右对齐或居中对齐；放在图片上的注释一律居中。

还可以选择一个 Logo 图片文件，并在文件选择框下方的选项面板里设置它的位置和不透明度。

勾选注释包含测量名称后，测量名称会出现在注释里，排在输入的注释文字前面。勾选默认文件名为测量名称后，图片保存为文件时，默认文件名就是测量名称。

这两个选项只在导出单个测量的图表时可用，导出叠加图图片时不可用。

有一个文本框显示着在此输入注释文字。在这个文本框里输入的文字，会按选定的注释位置出现在图片上：图表上方、下方或图表上。文字可以用 HTML 4.01 标签设置格式。放在图表上方或下方的文字，按注释的对齐方式对齐。

输入的注释文字会保留到下次打开这个对话框时继续使用，可以用清除注释按钮清掉。

插入当前测量备注按钮会把当前选中测量的备注（notes）插入注释。预览注释按钮用来在继续之前检查格式效果。放在图表上的注释文字居中显示。

图表会按选定的图片类型保存为 JPEG 或 PNG 文件，或者复制到剪贴板。



滚动条按钮


滚动条按钮用来打开或关闭图表区的滚动条。隐藏滚动条可以给图表腾出更多空间。这个设置下次启动时仍然有效。关闭滚动条后，仍然可以在图表区内按住鼠标右键拖动来移动图表。

频率轴按钮


频率轴按钮让频率轴在对数和线性两种模式之间切换。图表菜单里有同样功能的命令，也可以用对应的快捷键。

坐标轴范围按钮


坐标轴范围按钮用来设定图表上、左、下、右四边的坐标轴范围（graph limits）。点击后会弹出一个对话框，在里面输入数值。数值边输入边生效，也可以点应用设置按钮统一应用。

对话框里另有两个按钮：按数据调整范围（快捷键 Ctrl+Alt+F）把坐标轴范围调整到覆盖全部数据；按数据调整 Y 轴（快捷键 Ctrl+Alt+Y）只调整 Y 轴范围来覆盖数据，X 轴范围保持不变。

在图表上双击，也能打开这个对话框。此外，把鼠标指针移到某条坐标轴的末端，滚动鼠标滚轮或在触控板上做滚动手势，也可以调整坐标轴范围。用滚轮调整时按住 Alt 键，可以微调。


3D 视图按钮


3D 视图按钮用 3D 查看器打开瀑布图或频谱图的数据。


图表选项按钮


如果当前图表类型有可调的控制选项，点图表选项按钮会弹出这些选项的菜单。

横轴缩放按钮


鼠标指针进入图表区时，会出现横轴缩放按钮。它们以光标位置为中心，按约 2 倍放大或缩小。

也可以用键盘缩放，或者把鼠标指针移到要缩放的坐标轴上，滚动鼠标滚轮或在触控板上做滚动手势。用滚轮时按住 Alt 键可以微调。

纵轴缩放按钮


鼠标指针进入图表区时，也会出现纵轴缩放按钮，用来在 Y 轴方向放大或缩小。

同样可以用键盘缩放，或者把鼠标指针移到要缩放的坐标轴上，滚动鼠标滚轮或在触控板上做滚动手势。用滚轮时按住 Alt 键可以微调。

可变缩放

REW 可以用拖动的方式连续缩放图表，即可变缩放（variable zoom）。操作有两种：按住鼠标中键；或者先按住右键，在不松开右键的同时再按住左键。然后拖动鼠标指针。

可变缩放启动后，图上会显示一个十字，把区域分成四个象限。根据鼠标指针所在的象限，可以在水平方向、垂直方向或两个方向同时放大或缩小。缩放量取决于鼠标指针从起点拖出的距离。



框选缩放

先按住 Ctrl 键，再按住鼠标右键拖动，就能画出一个缩放框。注意：在 Mac 上可能需要同时按住 Ctrl 和 fn 键，或者按住 Ctrl 后在触控板上用两指拖动。

框的外侧会显示测量标线，标出框的宽度和高度。在阴影区域内单击，就会放大到这个区域。如果阴影区域太小、无法放大，会有提示说明是哪个方向的尺寸不够，以及至少要多大才能缩放。



用鼠标滚轮缩放

鼠标滚轮可以用来放大或缩小图表，按住 Alt 键可以微调。只想缩放 X 轴时，按住 Shift 键，或者把鼠标指针移到 X 轴上。要关闭滚轮缩放，见设置 → 视图。

用键盘缩放

横轴放大按 Shift+x，缩小按 x；纵轴放大按 Shift+y，缩小按 y。缩放以光标位置为中心。可能需要先在图表上单击一下。

撤销缩放

要撤销上一次的可变缩放或框选缩放，按 Ctrl+Z，或者选择图表菜单里的撤销缩放。图表坐标轴会恢复到上一次按下鼠标右键或中键时的设置。

即使没有缩放过，也可以用这个撤销功能：在坐标轴设置合适时按一下鼠标右键，之后不管怎样移动图表或改动控件，按 Ctrl+Z 都能回到这组设置。

方向键

方向键可以让图表光标每次移动一个像素。可能需要先在图表上单击一下。如果要移动的是图表而不是光标，按方向键时同时按住 Shift 键。

移动图表

按住 Alt 键，再按住鼠标左键拖动，就可以移动图表。
