视图设置

“设置 → 视图”页签用来设定 REW 的外观。



使用粗线条和曲线抗锯齿（anti-aliasing）能让图表更好看，但在某些平台上可能拖慢绘图速度。想画得快一些，就取消勾选这两项。 勾选平均值使用粗线条后，由其他测量平均得到的测量，在叠加图或测量缩略图里会画成更粗的曲线。

勾选启用鼠标滚轮缩放后，可以用鼠标滚轮或触控板放大、缩小图表；按住 Shift 键则只缩放横轴。勾选限制滚轮缩放速率，可以防止图表缩放得太快。

勾选保存曲线颜色设置后，曲线颜色设置会一起存进测量文件。

高亮曲线有一组选项（在“曲线高亮选项”下拉框里）。高亮曲线使用粗线条和使用黄色底纹高亮都能让高亮的曲线更醒目。勾选显示高亮曲线名称后，高亮某条曲线时，图表上会显示它的名称。

勾选图表显示水印后，水印文字框里的文字会作为背景显示在所有图表上（瀑布图和频谱图除外），不透明度用水印不透明度设定。

频率轴起点设定图表上能显示的最低频率。勾选显示宽高比 dB/十倍频后，鼠标指针停在频率响应图上时，图表右下角附近会显示该图的宽高比（aspect ratio）。

频率轴预设 1 和 2 会以两个按钮的形式出现在图表上。点击按钮，频率轴会快速切换到这里定义的相应预设范围，同时应用对应的 IEC 263 宽高比；如果宽高比选的是“按绘图比例”，则不改变宽高比。

默认曲线颜色按钮会打开一个面板，可以修改默认的曲线颜色，或恢复为 REW 的默认值。鼠标指针停在颜色按钮上时，会显示该曲线颜色的 R、G、B 值。这些默认颜色会保存下来，下次启动 REW 时沿用。

修改默认颜色不会改变已载入测量的曲线颜色。要改已有测量的颜色，用测量面板右键菜单里的颜色按钮，或者点颜色选择面板上的 Set All Trace Colours To Defaults（将所有曲线颜色设为默认）按钮。

界面

显示/隐藏选项里是一组设置，用来显示或隐藏界面上的各个元素。

勾选隐藏欢迎信息后，REW 启动时不再显示欢迎信息。

勾选显示辅助网格线后，图表除了主网格线，还会显示辅助网格线。

取消勾选缩略图显示网格，就能关掉测量缩略图上的网格。

勾选显示工具栏后，菜单下方会显示工具栏。在低分辨率屏幕上隐藏工具栏，可以给图表腾出更多空间。

取消勾选显示工具栏文本标签，可以隐藏工具栏按钮下方的文字；取消勾选图表按钮显示文字，可以隐藏图表按钮下方的文字。

勾选显示相位缠绕线后，相位曲线的缠绕点（wrap point）用虚线标出。

勾选缩略图显示测量电平后，每条测量的缩略图上会显示这次测量所用的信号电平。

勾选在缩略图上显示测量索引（默认勾选）时，测量的索引号显示在它的缩略图上。

关掉这一项，索引号改为显示在测量名称前面。这样缩略图不必重新生成，测量很多时，列表的更新会更快。

勾选移除未保存测量时确认后，如果要移除的测量在最近一次修改之后还没保存，REW 会先请你确认。这项设置也可以在移除确认对话框里修改。

勾选显示测量面板备注后，测量的备注会显示在测量面板上，显示的行数不超过显示备注行数的设定值。

勾选显示叠加面板备注后，测量的备注会显示在叠加图的测量面板上，显示的行数不超过显示备注行数的设定值。

勾选禁用工具提示后，鼠标指针停在控件或组件上时，不再弹出工具提示（tooltip）。

勾选控制面板不透明后，图表曲线不会透过图表选项面板显示出来。

勾选右键拖拽平移图表后，按住鼠标右键即进入图表平移（pan）模式。如果图表平移超过几个像素，就不会弹出右键菜单。

另外，按住鼠标左键不放，或者按住 Alt 键再按鼠标左键，也可以平移图表。

勾选抑制声卡错误后，如果启动时无法访问声卡，REW 不会显示错误信息或警告。如果只是在一台没有测量用音频接口的电脑上用 REW 分析测量，这一项会有用。

勾选动画显示测量列表后，测量列表的变化会以动画方式呈现。

勾选满量程正弦波 RMS 为 0 dBFS 后，满量程（Full Scale）正弦波的 RMS 电平显示为 0 dBFS；不勾选时，显示为 -3 dBFS。

勾选这一项后，某些信号的 RMS 电平可能会大于 0 dBFS，例如满量程方波的 RMS 电平是 +3 dBFS。

勾选鼠标悬停时滚轮调整控件后，鼠标指针停在数值框（spinner）或下拉框上时，滚动滚轮就能调整它的值；滚动时按住 Alt 键可以微调。

不勾选这一项，也可以先选中数值框，再用滚轮调整。

窗口置顶选项里是一组设置，用来让某些窗口始终显示在其他窗口上面。

在配色方案里选择要用的配色方案。重启 REW 后，所有组件的颜色才会全部更新。

距离单位用来选择距离以米显示，还是以英尺和英寸显示。

声速设定 REW 所用的声速值，用于把时间换算成距离、计算模态共振（modal resonance）等。默认值是 343.0 m/s，约为 20 ℃ 干燥空气中的声速。

调音基准频率设定音名（musical note）的参考频率，默认 440 Hz。

八度标记法用来选择显示音名时采用哪种标记方式。

字体选项里是影响 REW 字号的几项设置。

全局字体大小是 REW 的基础字号（单位：磅）。图表字体大小是图表坐标轴所用的字号。改动字号后，要到下次启动 REW 才生效。

最大测量数是 REW 里最多能载入的测量条数。改动后要到下次启动 REW 才生效。

注意：最大测量数设得很高时，REW 可能会内存不足。遇到这种情况，可以在安装时调大 REW 启动时申请的内存。

最大 RTA 输入数和最大电平表输入数设定多通道测量（Pro 升级功能）时最多显示多少路输入。改动后要到下次启动 REW 才生效。

在 macOS 上勾选使用 macOS 文件对话框后，文件选择对话框会换成更接近 macOS 原生样式的文件选择器。但要注意，macOS 的选择器没有预览面板，而 REW 正是用这个面板显示 mdat、req、校准数据和图片文件的内容。

有用户反映，原生文件选择器偶尔不出现。遇到这种情况，可以试着改回 Java 文件选择器。

使用 AZERTY 键盘是 macOS 上提供的一个选项，用来绕开一个导致快捷键映射出错的 Java 缺陷（JDK-8019498）。
