校准文件

此处列出了所有先前在 REW 中选取过的输出与输入，以及为它们指定的任何校准文件。选择输出设备与输出、或输入设备与输入时，REW 会自动加载关联的校准文件。不再需要的项目可以删除。可以使用浏览按钮来新增个别校准文件，或使用删除按钮将其移除。校准数据会在加载后应用至所有新的测量值，并会显示在测量值的 SPL 与相位图表上。目前作用中的项目会以高亮标示。新测量值将使用的校准文件可通过测量对话框中的 校准文件 按钮查看。

声卡校准文件是针对所使用的采样率而定的。如果采样率变更，将会加载该采样率的校准文件（若有）。

麦克风校准项目有额外的设置，可通过按下项目旁的设置按钮（齿轮图标）来访问。如果您使用 C 计权声压计作为 REW 的输入，请勾选 输入设备为 C 计权声压计，之后测量结果将会被校正，以移除 C 计权特性中的低频与高频滚降。如果同时也加载了校准文件，则校正仅会应用在校准文件涵盖频率范围之外的区域。

麦克风校准文件可应用至设备上的所有输入；或者，若勾选 各输入通道独立校准，则可为设备的不同输入分别指定单独的校准文件。例如，miniDSP EARS 耳机测量系统的左输入与右输入就有各自的校准文件。请注意，大多数 USB 麦克风是单声道设备，左右声道会提供相同的数据，这类设备适合使用单一校准文件。

94 dB SPL 对应的 dBFS 值 与 满量程声压级 字段可用于校准输入的声压读数。如果将麦克风放入 94 dB 校准器中，可以在此输入 dBFS 的读数（来自 电平表 或 声压计）。或者，如果已知满量程输入所对应的声压，也可以直接输入。如果校准文件内含灵敏度数值，这些字段将会禁用，此时显示的数值则由该灵敏度项目决定。

满量程正弦波 Vrms 数值用于校准电子测量时的输入读数。应设为一个正弦波的均方根电压，该正弦波的峰值刚好达到满量程。

若要对现有的测量值应用或移除校准文件，请使用测量面板右键菜单中的 更改校准 动作。

若要将 REW 的声压计读数与外部仪表进行校准，请使用声压计控件中的 校准 按钮。
