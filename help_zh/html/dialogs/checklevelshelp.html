检查电平 会以 扫频电平（REW 产生测量扫频信号的电平，默认为 -12 dBFS）产生低音炮或音箱的校准信号。需要调整播放音量、AV 处理器的音量以及（必要时）扫频电平，以达到您希望在室内测量的声压级，通常为 75 dB。请使用您的声压计来检查此电平，若声压低于或高于预期，请调整播放音量、AV 处理器的音量（优先）或 扫频电平（若直接连接至均衡器、低音炮或功放）。AV 处理器音量的初始设置应为您平常聆听时所使用的电平。

如果您使用 USB 麦克风，请将输入音量控件设为其单位增益（0 dB）设置，这在初次插入麦克风时即为默认值。使用 USB 麦克风时，输入电平通常约在 -30 至 -50 dBFS 之间。若不是使用 USB 麦克风，当校准信号播放时，输入电平理想上应介于 -30 至 -12 dBFS 之间。若电平过低或过高，请使用 REW 控件（若已启用）、您的接口或操作系统的音频音量控件来调整 输入音量。高于 -12 dB 的电平可能会导致测量时输入信号削波，低于 -30 dB 的电平则会使结果噪声较多，但这两者都不是绝对限制。
