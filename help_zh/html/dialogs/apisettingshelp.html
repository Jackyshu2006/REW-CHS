REW 提供了一个可通过 http 访问的 REST API，地址为 localhost (127.0.0.1)，默认端口为 4735。此 API 无法从运行 REW 的机器外部访问。可在端口字段中输入介于 1024 到 65535 之间的端口号，以指定 REW 要使用的端口。若要启动 API 服务器，请使用上方的按钮，或勾选 REW 启动时启动 API 选项，或使用 -api 参数运行 REW。在 Windows 上，使用默认安装的 REW 可通过下列方式执行：

C:\Program Files\REW\roomeqwizard.exe -api

在 macOS 上，可通过终端使用下列命令执行：

open -a REW.app --args -api

若要指定不同的端口（例如 4567），请再加上另一个参数 -port 4567。低于 1024 的端口号将被忽略。

当 API 执行时，所有 GET 方法皆可使用，允许通过 API 从 REW 获取数据。对大多数端点而言，默认也支持 PUT 与 POST 方法，但若要通过 API 控制 REW 以进行自动化扫频测量，则需要 Pro 升级版授权。

API 帮助文档由 swagger-ui 提供，可通过浏览 localhost:4735 来访问。API 的 OpenAPI 规范可通过 localhost:4735/doc.json（JSON 格式）或 localhost:4735/doc.yaml（YAML 格式）访问。使用数据模型来设置数值时，可通过 POST 方法进行；对于包含多个字段的模型，则可使用 PUT 方法，不过这两种方法都接受仅包含定义字段子集的数据模型。
