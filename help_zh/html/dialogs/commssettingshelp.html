若要启用 MIDI 端口选择，请勾选 启用 MIDI。在 macOS 下，MIDI 端口选择默认为禁用，因为在某些 Mac 电脑上访问 MIDI 会导致 Java 运行时环境崩溃。

如果您使用的均衡器具备 REW 支持的 MIDI 接口，请选择一个 MIDI 输出端口。REW 可通过 MIDI 对 BFD Pro DSP1124P 与 FBQ2496 进行设置，详细的设备设置方式请参阅主帮助文档。

注意：只有当“通信设置”选项卡首次打开时就已经存在的端口才会显示在选择列表中。若要在查看“通信设置”后才连接接口，则需要重新启动 REW 才能检测到。

FBQ 滤波器延迟 设置控制了 REW 在发送每一组滤波器设置至 FBQ2496 之间等待的时间长度。如果滤波器设置的传输不稳定，增加此延迟可能有助于改善。
