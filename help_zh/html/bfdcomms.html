与 BFD Pro DSP1124P 和 FBQ2496 通信

BFD Pro DSP1124P 和 FBQ2496 支持 MIDI 通信，可以通过 MIDI 设置滤波器和工作模式。要通过 MIDI 与这两台设备通信，需要一个 MIDI 接口（MIDI interface），例如 Edirol UM-1X USB-MIDI 接口或 M-Audio UNO。

把 MIDI 接口上标有“OUT”的插头，插到 BFD 上标有“IN”的插座。UM-1X 的 OUT 插头外壳上压印有“Connect to Midi IN”字样。

BFD 的 MIDI OUT 不必接。

MIDI 输出端口在设置 → 通信中选择。选好端口之前，REW 无法通过 MIDI 通信。所选端口会保存下来，下次启动时沿用。

Windows 平台支持 MIDI 通信。Linux 平台需要安装 Tritonus（www.tritonus.org）才能支持 MIDI 通信。装有 Java 运行环境（JRE）V6 或更高版本的 macOS 应该也支持 MIDI。

设置 DSP1124P 的 MIDI 通信



DSP1124P 出厂默认关闭 MIDI 通信。要启用 REW 用到的 MIDI 功能，需要按下面的步骤设置设备的 MIDI 菜单（下文提到的按钮都在 DSP1124P 前面板上）：

  1. 同时按下 IN/OUT 和 STORE 两个按钮，进入 MIDI 菜单。两个按钮里的 LED 开始闪烁，显示屏显示如下：

  2. 这是 MIDI 通道菜单，此时最右一位显示“c”。通道显示为“-”时，MIDI 处于关闭状态。转动飞梭旋钮（jog wheel），把通道改为 1：

  3. 按两次 IN/OUT 按钮，切换到 Controller（控制器）菜单，此时最右一位显示“C”。转动飞梭旋钮，选择模式 3：

  4. 再按一次 IN/OUT 按钮，切换到 Program（程序）菜单，此时最右一位显示“P”。转动飞梭旋钮，选择模式 3：

  5. 再按一次 IN/OUT 按钮，切换到 Store Enable（允许存储）菜单，此时最右一位显示“S”。转动飞梭旋钮，把数值设为 1：

    这样 REW 才能把设置存进 DSP1124P 的预设（preset）里。
  6. 再按两次 IN/OUT 按钮，退出 MIDI 菜单。

至此，DSP1124P 的 MIDI 通信设置完成。除 Store Enable 以外，这些设置在设备下次开机时仍然保留，不必重新设置。

设置 FBQ2496 的 MIDI 通信


FBQ2496 出厂默认开启 MIDI 通信。如果 MIDI 通信已被关闭，或者通道不是 1，按下面的步骤操作（下文提到的按钮都在前面板上）：

  1. 先确认设备不在 PEQ 模式：PEQ 按钮里的 LED 必须是灭的，如果亮着，按一下 PEQ 按钮把它关掉。

    然后同时按下 BANDWIDTH 和 BYPASS 两个按钮，进入 MIDI 菜单。两个按钮里的 LED 开始闪烁，数码显示屏下方的 MIDI 指示灯也跟着闪烁。显示屏上显示的是 MIDI 的开关状态：如果显示 OFF，转动旋钮，直到变成 on。

    接着按 BANDWIDTH 按钮，切换到 MIDI 通道菜单，显示屏上显示 C，后面跟着通道号。转动旋钮选择通道 1。
  2. 按 BANDWIDTH、BYPASS 以外的任意按钮，退出 MIDI 菜单。

至此，FBQ2496 的 MIDI 通信设置完成。这些设置在设备下次开机时仍然保留，不必重新设置。

注意事项

  1. DSP1124P 每次开机都会关掉 Store Enable。因此使用 DSP1124P 时，REW 会在每轮测量开始时提示你打开 Store Enable。

    如果不打开 Store Enable，REW 就无法把滤波器设置存进预设。滤波器发送到 DSP1124P 之后，STORE 按钮里的红色 LED 会一直闪烁，提醒你设置已经改动、但还没有存储。

    也可以手动存进预设：按 STORE 按钮，转动飞梭旋钮选好要存入的预设，再按一次 STORE 按钮。如果当前已经在要用的那个预设上，直接连按两次 STORE 按钮即可。
  2. MIDI 通信期间，DSP1124P 的 IN/OUT 按钮 LED 会闪动，FBQ2496 则是 MIDI 指示灯闪动。
  3. 向 FBQ2496 发送滤波器时，REW 会让接收滤波器的那个通道使用 20 个参数式滤波器（parametric filter）。发送完成后，如果设备处于旁路（bypass）状态，REW 还会关闭旁路。
  4. 发送一组滤波器，每个滤波器大约需要 1 秒。
