信号与测量

“这一堆东西到底 是什么意思？”

要读懂用 REW 做出的测量，最好先弄清这些测量到底是什么。本主题概述信号与测量的基础知识，说明 REW 中各种图表是怎样生成的，以及它们和实际测量结果有什么关系。

信号、采样率与分辨率

先弄明白什么是信号，至少要明白它在声学测量里指什么。我们关心的信号，是用麦克风或声压计（SPL meter，SPL 即 Sound Pressure Level，声压级）录下的声音。声压在麦克风里转成电信号，由音频接口捕获。接口在输入端测量电平，每测一次，得到的就是一个采样（sample）。

接口多久采样一次，由采样率（sample rate）决定。REW 支持的采样率取决于接口的能力，常见的是 44.1 kHz 或 48 kHz，也就是接口每秒在输入端捕获 44100 或 48000 次电平。以 48 kHz 采样 3 秒的信号，是 3×48000 = 144000 个测量值。

某个采样率下能记录的最高频率，等于采样率的一半。因为要还原一个频率，它的每个周期至少需要两个采样。所以 48 kHz 采样时，能捕获的最高频率是 24 kHz。

高于采样率一半的频率会引起混叠（aliasing）：它们看起来比实际频率低。比如 25 kHz 的信号用 48 kHz 采样，看上去像 23 kHz。为防止混叠，接口输入端有抗混叠滤波器，尽量拦掉超出上限的信号。但它们不能完全拦住，所以我们始终要留意想捕获的信号含有哪些频率成分。

接口测量的分辨率（resolution）通常是 16 位或 24 位。16 位与 CD 所用的相同，也是 REW 支持的分辨率。16 位意味着每个测量值可能取到的范围是 −32768 到 +32767（15 个二进制位存数值，第 16 位存符号）。

直接用这些数值不方便，更方便的做法是看它们离最大值有多近。这个最大值叫满量程（Full Scale，FS），也就是 −32768 和 +32767。最小的非零测量值是 1，占满量程的 100×(1/32768)，约 0.003% FS。比这更小的值，接口都当成零。

满量程对应输入端的某个电压，通常在 1 伏左右。分辨率更高的声卡（如 24 位），最大输入电压通常相同（约 1 伏），只是用更大范围的数来度量电压。24 位接口的满量程测量值是 −8388608 和 +8388607。最大输入电压没变，通常仍是 1 伏，变的是分辨率：它能检测的最小值只有满量程的 0.000012% FS。分辨率高的好处，体现在最微弱的信号上。

满量程常被当作 1，低于满量程的值按所占比例算，半满量程就是 0.5，依此类推。

削波

如果信号大过满量程值，接口就跟不上了：不管输入端实际发生什么，测量值都不会高过满量程。信号一旦超出输入能测量的范围，就称它被削波（clipped）了。

削波在输入信号中表现为平坦段。如果削波发生在接口输入端，平顶会出现在 +100% FS 或 −100% FS 处，REW 会向你发出警告。

但有时削波在信号到达接口之前就已经发生，例如麦克风前置放大器的增益设得太高。这种情况下，测量值可能始终达不到接口的满量程，信号却照样被削波了。

测量时必须避免削波。被削波的信号已经不能代表输入端真实发生的情况，会破坏测量结果。

查看信号

查看信号的一种方式，是把测量值对着时间画出来。

在 REW 的采集信号（Captured）图上画被捕获的信号时，纵轴用 % FS（满量程百分比）。达到 100% FS 的信号，就是接口能捕获的最大信号。

我们通常关心的不止是采样值，也关心构成这个信号的频率。频谱（spectrum）指构成一个信号的频率范围，可以用快速傅里叶变换（FFT）算出来。

FFT 会算出一组余弦波的幅度和相位。把这些余弦波加在一起，得到的测量值序列与原时间信号相同。幅度和相位是表示同一个时间信号的另一种方式：用构成它的频率来描述，而不是用一个个测量值。

幅度容易理解：幅度越大，余弦波越大。相位表示各条余弦波在所测序列第一个采样时刻的起始值。相位为 0 度，起始值是 幅度×cos(0) = 幅度；相位为 90 度，起始值是 幅度×cos(90) = 0。

我们平时更关心幅度，而不是相位，但不能完全忘了相位：它包含了原时间信号形状的一半信息。

用 FFT 计算频谱时，使用的是一组均匀分布的频率。这组频率从直流（DC，零频率）开始，一直到采样率的一半，也就是能被正确表示的上限。

频率之间的间隔，取决于送入 FFT 分析的信号有多长。信号长度取 2 的幂时，FFT 的计算效率最高，例如 16k（16384）、32k（32768）、64k（65536）。

举个例子。对一段 48 kHz 采样的信号做 64k FFT，需要 65536/48000 秒的信号，即 1.365 秒。这时频率间隔是 24000/65536 = 0.366 Hz。如果改用 16k 个采样，间隔变成 1.465 Hz。

可见，用于 FFT 的采样越少，频率间隔越大，频率分辨率越低。想要高的频率分辨率，就得分析更长时段的信号。

RTA

查看时间信号的频谱，另一种常用方式是实时分析仪（Real Time Analyser，RTA）。它画出所分析信号中各个频率的幅度。

RTA 和 FFT 的区别在于分组方式。FFT 给出的频率是均匀间隔的，而 RTA 按几分之一倍频程为一格，把这些频率归并在一起。

倍频程（octave）就是频率翻一倍。所以 100 Hz 到 200 Hz 是一个倍频程，1 kHz 到 2 kHz 也是一个。频率越高，同样一个倍频程分数所覆盖的实际频率范围越宽。以 1/3 倍频程 RTA 为例：在 20 Hz 处，一格的跨度约 4.6 Hz；在 20 kHz 处，一格的跨度是 4.6 kHz。换成 1/24 倍频程 RTA，每格宽度只有前者的 1/8。

在一个倍频程分数的跨度内，可能要用到许多个 FFT 值，才得出 RTA 赋给这段频率的那一个值。下面是 REW RTA 的一张图，显示一个 1 kHz 单音及其失真谐波的频谱。


系统与传递函数

看一个信号的频谱有它的用处，但我们还关心：所用器材会怎样改变信号的频谱。

一个系统改变通过它的信号频谱的方式，叫这个系统的传递函数（transfer function）。传递函数有两个组成部分：频率响应（frequency response）和相位响应（phase response）。频率响应说明系统如何改变各个频率的幅度，相位响应说明系统如何改变各个频率的相位。

要完整描述一个系统，需要这两条响应。差别很大的两个系统，可能有相同的频率响应，但它们的相位响应不同，我们正是靠这一点把它们区分开。

要特别注意：别把系统的频率响应，和系统输出信号的频谱混为一谈。信号的频谱，告诉我们这个信号由哪些频率构成；传递函数的频率响应，告诉我们系统如何改变信号的频谱。

像 REW 这样的测量软件，目的就是测量传递函数。REW 的 SPL & 相位（SPL & Phase）图显示传递函数的频率响应和相位响应，其中频率响应的幅度用一条 SPL 曲线表示。下面这张图来自一次房间测量，横轴画到 200 Hz：上方曲线（对应左侧纵轴）是频率响应，下方曲线（对应右侧纵轴）是相位响应。


脉冲响应

传递函数通过频率响应和相位响应，说明系统如何影响通过它的信号频谱。这是在频域（frequency domain）里刻画系统。可信号本身呢？系统如何改变信号的一个个采样，也就是它在时域（time domain）里的表现，又该怎么描述呢？

系统改变信号采样的方式，叫它的脉冲响应（impulse response，简称 IR）。这个名字的由来，后面会清楚。

脉冲响应本身也是一个信号，由一串采样组成。输入信号经过系统时，会和脉冲响应重叠，并沿着它逐个采样地向前滑动。信号刚出现时，它的第一个采样对齐脉冲响应的第一个采样。这一刻的系统输出，是输入的第一个采样值乘以 IR 的第一个采样值：

output[1] = input[1]*IR[1]

过一个采样间隔，输入和 IR 有了 2 个采样的叠合。这一时刻的输出，是输入的第 2 个采样乘 IR 的第 1 个采样，加上输入的第 1 个采样乘 IR 的第 2 个采样：

output[2] = input[2]*IR[1] + input[1]*IR[2]

再过一个采样间隔，输入和 IR 叠合了 3 个采样，输出是：

output[3] = input[3]*IR[1] + input[2]*IR[2] + input[1]*IR[3]

随着后面每一个输入采样出现，这个过程一直继续下去。把输入信号采样和 IR 采样相乘再相加的这个过程，叫卷积（convolution）。

脉冲响应一般都不长：测一件器材，远不到一秒；测一个家用大小的房间，也就一两秒。所以最终，每一时刻的输出，都是用一整段 IR 去乘同样长的一段输入信号，再把所有乘积加起来，得出那一时刻的输出值。

那为什么叫“脉冲响应”？

设想这样一个输入信号：只有第一个采样是满量程（我们把它取值为 1），后面所有采样都是 0。这时系统会输出什么？第一个输出采样是：

output[1] = input[1]*IR[1] = IR[1]

第二个输出采样是：

output[2] = input[2]*IR[1] + input[1]*IR[2] = 0*IR[1] + 1*IR[2] = IR[2]

第三个是：

output[3] = input[3]*IR[1] + input[2]*IR[2] + input[1]*IR[3] = 0*IR[1] + 0*IR[2] + 1*IR[3] = IR[3]

依此类推。输出会依次是 IR 的每一个采样。

这种“只有一个满量程采样、后面全是 0”的输入，叫一个脉冲（impulse）。所以，给系统输入这个脉冲时，系统的输出叫这个系统的脉冲响应。

传递函数与脉冲响应的关系

传递函数和脉冲响应描述的是同一个系统，所以我们有理由推测两者有关系，事实也确实如此。传递函数是脉冲响应的 FFT，脉冲响应则是传递函数的快速傅里叶逆变换（IFFT，inverse FFT）。

它们是同一个系统的两种视角：一个在频域，一个在时域。传递函数就是脉冲响应的频谱。

查看脉冲响应

REW 的“脉冲（Impulse）”图显示的是脉冲响应，纵轴可以用 % FS，也可以用 dBFS。

dB 刻度的好处，是能看到信号更大的动态范围。它不直接画数值，而是画数值以 10 为底的对数再乘以 20。dB 图的顶端是 0 dBFS，对应 100% FS。50% FS 是 20×log(0.5) = −6 dBFS，10% FS 是 20×log(0.1) = −20 dBFS。

用 dBFS 刻度，可以看清脉冲最微弱的部分是什么状态，以及它在哪里淹没到测量的噪声电平以下。下面两张图是同一条脉冲响应：第一张纵轴用 % FS，第二张用 dBFS。第二张图显示，脉冲衰减到测量的本底噪声里所花的时间，比只看 % FS 图时感觉的要长。



对脉冲响应加窗

我们想测的系统，可能是一件器材，比如一只扬声器。但在声学里，我们实际测到的系统，还包括测量信号生成之后、到信号被拾取用于分析之前，这一路上的其他器材和环境。

这些环节包括功放、麦克风、音频接口，以及最重要的房间本身。我们实际测的，是所有这些环节合在一起的结果。所以，想单独看其中一部分，就得有办法去掉我们不关心的那些环节的影响。

接口的响应可以单独测出来，再校准扣除，麦克风的响应也一样。去掉房间的影响要难得多。

有时房间的影响正是我们关心的，尤其是研究听音位置上听到的声音时。但如果要单独看清一只扬声器的表现，房间叠加进来的成分可能盖住扬声器本身的细节。

声音到达麦克风，最先走的是直达路径。这是从扬声器到麦克风最短的路，用时也最短。同时，扬声器发出的声音还向四周辐射，被房间的各个面反射。这些反射要走更远的路才能到达麦克风，所以到得更晚。

假如输入信号是一个脉冲，我们会先看到直达声，再看到一个个反射声到达。这些较晚的到达，是因为多走了一段距离、多花了时间。

这段多出来的时间，最短也不会短于声音走到最近反射面所需的时间。举个例子，如果最近的面在 3 英尺（约 0.9 米）外，它的反射到达麦克风，至少比扬声器的直达声晚 3 毫秒（实际会再晚一点，因为反射路径比 3 英尺略长）。

如果只看脉冲响应最前面的几毫秒，看到的就是最初到达的那部分。它直接来自扬声器，不含房间的成分。像这样只截取脉冲响应的一小段来看，叫对响应做窗函数处理（windowing）（在前面几段的脉冲响应图里，蓝色曲线画的就是窗）。

对这段加了窗的 IR 做 FFT，就能得到这段直达声的传递函数，也就是扬声器单独的传递函数。

不过这样做有个缺点。对一段短信号做 FFT，能看到的频率有个下限，下限取决于信号有多长。信号有整整一秒，频率响应能一直看到 1 Hz；只有十分之一秒，就只能看到 10 Hz。一般来说，分析的信号长度是 T 秒，最低频率就是 1/T。所以，如果窗只有 3 毫秒长，频率响应就只能低到 1/0.003 = 333 Hz。

因此，想看到不受房间影响的低频响应，最近的表面要尽量远。要在 REW 里调整窗设置，点 IR 时间窗（IR Windows）按钮。REW 默认的窗设置包含 0.5 秒以上的脉冲响应，所以能看到房间的影响。

瀑布图

研究我们测到的传递函数，“SPL & 相位”图和“脉冲”图最有用。但还有一张图，能告诉我们房间对其中播放的声音做了什么，那就是瀑布图（waterfall plot）。

瀑布图画的是脉冲响应中某一段的频谱怎样随时间变化。画法是：先对响应最前面的一段加窗（看房间响应时一般取几百毫秒），对这段加窗部分算一次 FFT，得到瀑布图的第一条切片。然后把窗沿脉冲响应向后挪一点，再算一次 FFT，得到第二条切片。窗再往后挪一点，得到第三条，然后是第四条，依此类推。

窗越往后挪，来自扬声器的最初成分越少，越来越多地只剩房间的成分。房间响应在有模态共振（modal resonance）的频率上最强。模态共振频率是这样一些频率：声音在房间各个表面之间来回反弹，在这些频率上自我增强，形成稳定、衰减很慢的音调。这些频率在瀑布图上凸起成一道道“山脊”。模态共振越严重，山脊越高，衰减也越久。
