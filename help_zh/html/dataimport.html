导入测量数据

REW 可以导入其他程序生成的频率响应（frequency response）和阻抗（impedance）测量数据，其中包括 ETF5 测量系统（http://www.acoustisoft.com）的数据。REW 支持 ETF5 的大多数导出格式，也支持通用的逗号、空格或制表符（Tab）分隔文本文件。

注意：用 ETF5 测量时，最好使用它的 calibrated SPL（校准 SPL）选项，这样不同声道之间才能比较电平。

ETF *.pcm 格式的脉冲响应

ETF 的全频段测量可以用 File → Write Impulse As *.pcm 选项，把脉冲响应（impulse response）导出为 .pcm 原始数据格式。

在 REW 里，用文件 → 导入脉冲响应命令载入这些文件。导入脉冲响应后，REW 就能用这些数据生成频谱衰减图和瀑布图（导入频率响应文本文件则做不到）。REW 读取文件的前 128k 个样本（采样率为 48 kHz 时约 2.73 秒）。

WAV、AIFF、Flac 或 MP3 格式的脉冲响应

文件 → 导入脉冲响应命令也可以载入以 .wav、.aiff、.mp3 或 .flac 格式保存的脉冲响应。REW 最多可从文件里载入约 60 秒的数据。

频率响应和阻抗文本文件

文件 → 导入频率响应和文件 → 导入阻抗测量两个命令接受扩展名为 .txt、.frd、.dat 或 .zma 的文本文件。

扩展名为 .zma 时，数据一律按阻抗处理。其他扩展名则看用哪个命令载入：用导入频率响应载入就按 SPL 处理，用导入阻抗测量载入就按阻抗处理。支持以下格式：

  • 通用的逗号、制表符、空格或分号分隔文件
    • 数据按“频率、幅度（SPL 或阻抗）、相位（可选，单位为度）”排列，每行一组数值。
    • 数据点的频率间隔可以任意，但每一行的频率都必须高于上一行，并且至少要有 5 组数据。
    • 只导入以数字开头的行，其他行一律忽略。
    • 用逗号分隔的文件，逗号后面至少要有一个空格。
    • 数值前面的空格会被忽略。
    • 要在数据行上加注释，在最后一个数值后面先加一个制表符、逗号或空格，再写注释。
  • ETF5 Low Frequency Room Response（低频房间响应）窗口的 Export Data（导出数据）选项
  • ETF5 的 Export Bode Response（导出伯德响应）选项
  • ETF5 Logarithmic Frequency Response（对数频率响应）窗口的 Export Data 选项
    • 数据点之间采用三次样条插值（cubic spline interpolation）。

逗号分隔文件格式

下面是一个格式有效的逗号分隔 SPL 数据示例，不含相位： 

            SPL measurements acquired by REW V3.08
            Source: D:\REW\test files\testfile.txt
            Format: Comma delimited data
            Dated: 05-Mar-2005 17:53:56
            Channel: Left, Bass limited 80Hz

            20.0, 65.01
            21.0, 65.77
            22.0, 67.50
            23.0, 67.93
            24.0, 68.22
            25.0, 67.88
            26.0, 67.92
            27.0, 68.31, this line has a comment
            28.0, 69.14
            29.0, 69.16
            30.0, 69.29

如果你所在地区用逗号作小数点，为了不产生歧义，最好用制表符、空格或分号作分隔符。
