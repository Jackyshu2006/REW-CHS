REW V5.40 更新说明

V5.40 新增了一种测量方法：快速子带自适应滤波（Fast Subband Adaptive Filtering，FSAF）。同时开放了 API，并新增测量分组功能。

测量列表换成了全新版本，拖放操作更顺手，还支持多选、剪切粘贴快捷键和筛选。 原来的操作面板取消，改由测量和图表的右键菜单调用。 瀑布图和频谱图新增了 3D 视图。

Java 运行环境已升级到 Java 17。

专业版

  • 新增了一个工具，按 IEC 60268-16:2020 用间接法计算语音传输指数（speech transmission index，STI）。
  • 多通道测量新增两个选项：一是用互相关对齐（cross correlation alignment）把各路独立测量对齐到第一路输入的测量， 二是对各路独立测量做向量平均（vector average）。

API

  • 新增：可通过 http 访问的 API，地址是 localhost (127.0.0.1)，默认端口 4735。

测量

  • 新增：可以用任意激励信号做测量，包括音乐和噪声。用的是 Michael Tsiroulnikov（又名 Michael Zrull） 开发的快速子带自适应滤波算法。
  • 新增：渐变电平（ramped levels）测量模式，可以在一段激励电平范围内连续做一系列测量。

其他与测量相关的变更：

  • 新增：可以把输出电平追加到测量名称后面。
  • 新增：在测量对话框里取消勾选“低输入电平时警告”，就能关掉输入电平过低的警告消息。
  • 高失真和低信噪比（SNR）的警告消息，也可以在测量对话框里关掉。
  • 变更：测量名称允许更长了，但图例里放不下时会截断显示。
  • 变更：声压记录器如果选了“滚动式”，Leq 曲线名和文件头里会带上滚动 Leq 的数值。
  • 变更：步进互调失真（IMD）图在 X 轴选“输入”时，横轴改用输入的 rms 电平， 不再像以前那样用 IMD 参考音的电平。
  • 变更：扫频失真测量改用频率相关时间窗，用来压低本底噪声，避免本底噪声随频率升高而抬升。

音频接口

  • 新增：设置 → 声卡里的虚拟平衡输入增加了“和／差”模式选择， 用来决定组成虚拟平衡输入的两路信号是相加还是相减。
  • 新增：可以给输入数据施加一个多项式。多项式系数可以在麦克风校准文件里指定，也可以在设置 → 校准文件里填写，或者通过 API 设定。
  • 变更：使用 ASIO 时，状态栏的采样格式信息会一并显示缓冲区大小。
  • 变更：Java 输出通道映射最多支持 24 个通道。

EQ

  • 新增：Acoustas 的 AirDSP 均衡器条目。
  • 新增：miniDSP Tide-16 均衡器条目。
  • 新增：ETON Audio 均衡器条目。
  • 新增：Sonance/Blaze 均衡器条目。
  • 新增：ESX Audio 均衡器条目。
  • 新增：Musway 均衡器条目。
  • 新增：把通用均衡器的系数保存到文件时，支持 Q-SYS 的 biquad 系数格式。
  • 新增：StormAudio 多了一个“EQ only”条目，带 20 个滤波器，但不含分频滤波器。
  • 新增：EQ 窗口的滤波器调整图新增一项操作，可以从另一条测量把滤波器复制过来。
  • 新增：滤波器调整图增加一个选项，可以选择在图上拖动编辑滤波器时是否显示滤波器参数。
  • 变更：更新了 StormAudio 均衡器的参数上下限和滤波器类型。
  • 变更：可配置均衡器的设置发生变化时不再弹提示。
  • 变更：频率步进为 1 Hz 或更大的可配置均衡器，改用随机优化算法（stochastic optimiser）。
  • 变更：滤波器响应曲线改成以 1 kHz 处的总目标响应电平为基准来画，不再以目标声压级的设定值为基准。
  • 变更：采样率跟随测量的均衡器（例如“通用”），在没有载入测量时改用 REW 的采样率。

脉冲响应

  • 新增：脉冲响应增加了多时间窗（multi-time window，MTW）选项， 窗宽按各倍频程中心频率分别指定。
  • 新增：在脉冲响应图上方的区域点击，就能设定左右时间窗的位置。
  • 新增：脉冲响应图和滤波 IR 图增加了“显示反射限制”选项，会叠加显示消声环境（anechoic）中 单次侧向反射（lateral reflection）的可闻阈值（Olive & Toole, 1989）。
  • 变更：叠加图的“偏移 t=0”窗口增加了“应用并上一项”和“应用并下一项”按钮，可以逐条测量往前后翻。
  • 变更：IACC 计算窗口改从“工具”菜单打开。

All SPL 图及其工具

  • 新增：在 All SPL 图和叠加图的 SPL 图上，可以把某条测量设为其他选中测量的参考。
  • 新增：对齐工具增加了设定允许延迟范围的控件。
  • 新增：对齐工具在相位对齐模式下增加了一个复选框，用来决定是否显示求和后的相位曲线。
  • 新增：对齐工具增加了一个选项，可以扣掉参与对齐的各条测量之间共有的时间延迟， 让第一条 IR 从 t=0 开始。这样能减少相位缠绕（phase wrap）。
  • 新增：All SPL 图增加了“向量和”操作，可以把多条测量相加。
  • 新增：部分曲线运算增加了一个选项，用来决定结果的频率范围是取两条曲线的重叠部分， 还是取两者合并后的范围（默认取合并范围）。
  • 新增：All SPL 图的测量右键菜单增加了一项操作，可以把某条测量设为当前选中的测量，各单张图表随之显示这条测量。
  • 新增：All SPL 的测量列表增加了一个按钮，可以按名称的字母顺序排序。
  • 变更：互相关对齐针对反射较强的测量做了改进。
  • 变更：对齐工具做相位对齐时，更看重对齐频率附近的相位吻合程度。
  • 变更：对齐工具的相位对齐改为取对齐频率两侧各 1/2 倍频程的范围。
  • 变更：曲线运算的除法改用最大增益值，不再用正则化（regularisation）值。
  • 变更：取消勾选“最大增益”复选框，就能关掉曲线运算除法和反演的增益限制。
  • 变更：做带频率范围限制的除法时，范围之外的目标设为增益为 1、相位为 0。
  • 变更：复制出来的响应会一并带上源测量的失真数据。

频谱图与瀑布图

  • 新增：瀑布图和频谱图支持 3D 视图。
  • 新增：频谱图的等高线间隔增加了 3 dB 和 6 dB 两个选项。
  • 新增：瀑布图可以按各频率的峰值做归一化。
  • 新增：瀑布图和频谱图增加了“将设置应用于全部”按钮，可以把当前设置复制到其他测量。
  • 新增：突发衰减模式的瀑布图和频谱图增加了更多倍频程分数选项。

叠加图窗口

  • 新增：针对步进电平测量，增加了“电平”和“线性度”两张叠加图。
  • 新增：叠加图的 SPL、预测 SPL 和失真三张图都增加了一个按钮，可以把一组测量以 3D 曲面的形式查看。
  • 新增：在脉冲响应叠加图上对某条测量做“偏移 t=0”时，曲线会实时跟着移动，同时显示对相位的影响。
  • 新增：叠加图的曲线选项里加入了测量名称。
  • 新增：如果选中的测量不含所选的失真指标，失真叠加图上会给出提示。
  • 新增：叠加图窗口的测量列表增加了一个按钮，可以按名称的字母顺序排序。
  • 新增：叠加图测量的右键菜单增加了“将选中项信息复制到剪贴板”操作。
  • 变更：叠加图换了一套挑选显示哪些测量的方式，用的是新测量列表的精简版。
  • 变更：载入 .mdat 文件时，会恢复保存时叠加图的选中状态。

信号发生器

  • 新增：信号发生器增加了音名选择器。
  • 新增：发生器可以产生非相关噪声信号。
  • 新增：发生器可以产生高斯分布噪声信号。
  • 新增：信号发生器增加了符合 IEC 60268-16:2020 的语音噪声信号。
  • 新增：抖动（jitter）测试信号可以选 16 位或 24 位。
  • 新增：双音发生器增加了“独立输出”选项，可以把 f1 和 f2 分别送到两路输出。
  • 新增：双音发生器增加了“将频率锁定到 RTA FFT”选项，可以把两个音的频率都调整到 FFT 频率区间（bin）的中心。
  • 新增：信号发生器增加了 DIM30 和 DIM100 两种动态互调失真（dynamic intermodulation distortion，DIM）测试信号。
  • 变更：CEA-2010 猝发信号的重复间隔改为跟随 RTA 的 FFT 长度，最短 1 秒。
  • 变更：满量程正弦波 Vrms 输入框的电压预设增加到 8 个。

声压计

  • 新增：声压计可以同时显示 SPL、Leq 和 SEL，三者的计权方式可以各自独立设置。
  • 修复：macOS 上用已校准的 UMIK 时，在声压计上点“校准”会要求提供校准文件，其实应该提示无需校准。

RTA

  • 新增：步进正弦测量增加了“THD vs 频率与电平”选项，可以在一段信号电平范围内做一系列 “THD vs 频率”的步进测量。
  • 新增：步进正弦测量增加了“IMD vs 频率”和“DFD vs 频率”两个选项。
  • 新增：RTA 的失真设置增加了互相关平均（cross correlation averaging）选项。当同一路信号同时接到测量输入和参考输入时，用它可以压低输入端的噪声。
  • 新增：拖到 RTA 上的立体声 WAV 文件也可以用互相关平均处理。
  • 新增：RTA 增加了寻峰器，用来找出频谱中的峰。
  • 新增：RTA 的图表选项里增加了一个选项，RTA 停止时一并停掉信号发生器。
  • 新增：RTA 的 ENOB 幅度校正可以在失真设置里关掉。
  • 新增：Y 轴为 SPL 时，外观设置里可以选择叠加显示听阈（hearing threshold）曲线。
  • 新增：失真设置增加了“显示音名”选项，会给基波标上对应的音名。
  • 新增：RTA 的多通道测量会为前两路输入分别显示峰值曲线。
  • 新增：RTA 增加了失真补偿面板。它分析输入的双音信号，据此生成一个校正多项式。
  • RTA 可以配合 DIM30、DIM100 信号分析动态互调失真。
  • 相干平均（coherent averaging）可以用于双音信号和多音信号，前提是 RTA 使用矩形窗（rectangular window）。用双音信号时，还需要勾选“将频率锁定到 RTA FFT”。
  • 变更：CEA-2010 猝发信号的 RTA 最大 SPL 限值，可以选 CEA 2010 (2006)、CTA-2010-B 或 CTA-2034-B。
  • 变更：自定义双音信号的幅度比为 4:1 时，REW 会按调制失真（modulation distortion）测量来确定 d3、d4、d5 对应的频率。
  • 变更：满量程正弦波 Vrms 输入框的电压预设增加到 8 个。
  • 变更：RTA“达到指定平均次数后停止”的选项，现在对文件数据也有效。
  • 变更：修订了贴近本底噪声的谐波的电平算法，减少噪声对结果的影响。
  • 变更：功率读数用的参考阻抗控件移到了 RTA 工具栏，取用更快。

示波器

  • 示波器增加了“保存”按钮，可以把当前曲线中可见的那一段保存成测量。

RT60 图

  • 新增：单张 RT60 图和叠加图的 RT60 图都可以叠加显示 EBU RT60 限制。
  • 新增：增加了设定 EBU 限制所用 RT60 标称值的控件。
  • 新增：叠加图的 RT60 图增加了“将平均值复制到剪贴板”操作。
  • 新增：如果设置 → 分析里的 IR 截断时长太短、不足以算准 RT60，会给出警告。
  • 变更：RT60 衰减图上半部分的 SPL 范围和时间范围，改成与下方瀑布图一致，只多留一点余量。
  • 变更：即使所取范围内的衰减量很小，Topt 也允许给出 RT60 结果。这样一来，如果做测量时设置 → 分析里的 IR 截断时长相对所测空间设得过短，这些测量也能挽回一部分数据。

数据导入与导出

  • 新增：支持导入 Flac 和 MP3 文件。
  • 新增：支持导入 lspCAD 的卷积脉冲 .txt 文件和 emulator 脉冲 .txt 文件。
  • 新增：IR 文本导出的文件头里会写入数据偏移量，日后再导入这个文件时会沿用该偏移量。
  • 新增：可以导入 Audio Science Review 的 SPL Vertical.txt 和 SPL Horizontal.txt 测量结果。
  • 新增：采集信号图的右键菜单增加了几个选项，可以把激励信号、测量信号或参考信号导出为 WAV 文件。
  • 新增：拖入的文件如果表头行里同时含有 “freq” 和 “ohm”，会按阻抗数据处理。
  • 变更：把 WAV、AIFF、Flac 或 MP3 文件拖到 REW 主窗口时，按住 Ctrl 键就会按音频导入处理， 而不是按 IR 导入处理。
  • 变更：从 REW 导出的阻抗数据文本文件，以及从 DATS 导出的数据，拖入 REW 时会按阻抗数据处理。
  • 变更：导入文件的名称排序改用字母数字比较，不再用字典序比较。

设置

  • 新增：设置 → 视图的“图表”一栏增加了“使用大图标”选项，方便触摸屏操作。
  • 新增：设置 → 视图增加了几项，可以在测量面板和叠加图的测量面板上显示备注，并设定显示几行备注。
  • 新增：设置 → 视图增加了两项，可以设定音名所用的调音基准频率（默认 440 Hz），并选择八度标记法的样式。
  • 新增：设置 → 视图增加了水印不透明度的控件。
  • 变更：“右键拖拽平移图表”可以在设置 → 视图里关掉。
  • 变更：设置 → 视图里不勾选“启用鼠标滚轮缩放”时，在坐标轴上滚动滚轮仍然可以缩放。

  • 变更：操作面板取消，改由图表的右键菜单调用，取用更快。
  • 新增：测量可以分组。
  • 新增：工具栏增加了曲线运算的图标。

Bug 修复

最后是一批 bug 修复：

  • 修复：无时间基准的多通道测量启用“保留相对时间”时，未能保持所选的 t=0 基准。
  • 修复：步进正弦的 THD 结果被限制在 9 次谐波，即使数据已经采到 50 次谐波。
  • 修复：“全部移除”的确认框可能被其他窗口挡在后面。
  • 修复：某些步进正弦测试设置会导致索引越界。
