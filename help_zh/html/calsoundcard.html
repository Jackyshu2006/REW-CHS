测量前的准备

在启动 REW 之前插好要用的音频接口（audio interface）和 USB 麦克风，REW 运行期间不要拔掉。

在 macOS 上可能还需要给 REW 开放麦克风权限，位置在系统设置的“安全性与隐私”下的“麦克风”一项。

用 REW 测量时，最好退出其他所有程序，断开网络连接，并关闭无线网络。

无线网卡会对音频输入造成干扰；其他程序、杀毒软件更新之类则会占用大量处理器资源。这两者都可能让生成或采集的音频信号出现断续，测量结果因此出错。

做房间测量，最初需要完成这几步：

  1. 选择音频输入与输出
  2. 校准音频接口 （使用 USB 麦克风时不需要这一步）
  3. 检查电平
  4. 校准 SPL 读数 （如果用的是 REW 能识别的 USB 麦克风，并且它的校准数据里带有 REW 兼容的灵敏度值，就不需要这一步。截至 2022 年 9 月，能识别的型号有 UMIK-1、UMIK-2、UMIK-X、EARS、CARIO-A2B、UMM-6、Omnimic 和 Beta Three）

这几项校准和电平检查通常只需要做一次。

第一次使用 REW，建议按顺序读完这几章入门内容，不要直接跳到某一个设置步骤。如果这台电脑已经为其他声学测量软件配置过，可以直接跳到开始测量。

选择音频输入与输出

在 Windows 上，REW 既可以用 Java 音频驱动，也可以用 ASIO 驱动；其他平台只支持 Java 驱动。

Windows 上的 Java 驱动有两种访问音频接口的方式：WASAPI 独占模式，或 JavaSound 自带的访问方式。JavaSound 自带方式最高只支持 192 kHz 的采样率（sample rate），而且只支持 16 位立体声数据（以上两项限制以撰写本文时的 Java 8 运行环境为准，时间是 2020 年 12 月）。WASAPI 独占模式则是音频接口支持哪些通道和采样率就提供哪些，并采用该接口所能提供的最高采样分辨率。

用 WASAPI 独占模式的设备，在 REW 的设备选择框里会带 EXCL: 前缀。注意，只有在 Windows 的设备音频属性里勾选了“允许应用程序独占控制该设备”的设备，才能使用 WASAPI 独占模式。

在 macOS 和 Linux 上，只要音频接口支持，就会使用 32 位或 24 位数据。macOS 最高支持 192 kHz 采样率，Linux 最高 1536 kHz。当前的采样率和采样格式／位宽（bit depth）显示在 REW 主窗口底部。用 Java 驱动时，输入和输出可以分属不同设备。

Windows 上的 ASIO 驱动，只要音频接口支持，最高可到 1536 kHz；支持哪些数据格式则随驱动而定。

ASIO 驱动只支持一个 ASIO 设备，输入和输出都得用这一个，而且 REW 无法控制它的电平。FlexASIO 这类伪 ASIO 驱动，做法是在设备的 WDM 驱动外面套一层 ASIO 封装驱动（ASIO wrapper）。有了这层封装，输入和输出就可以分别走不同的设备。

用 Java 驱动时，REW 默认使用操作系统里设为默认的那个音频输入和输出。这个默认项会随着音频设备的插拔而变化；而且保持默认时，REW 无法判断设备的具体能力，比如它支持哪些位宽和采样率。

所以强烈建议在设置 → 声卡面板里，明确选定测量要用的设备、输入和输出，不要让它停留在默认。点击工具栏上的“设置”按钮即可打开该面板。

设备列表里列出的是 REW 检测到的全部音频接口。选中某个接口后，输入和输出列表就会显示这个接口上可用的输入／输出。ASIO 设备只要装了驱动就会出现在列表里，接口没接上也一样；把接口接上，支持的采样率列表才会填出来。

注 1：如果在 REW 启动之后才插入 USB 接口，它可能要过一分钟才会出现在设备列表里——这是 Java 运行环境（Java Runtime Environment）本身的特性。

注 2：如果用的是 ASIO4All，并且在 ASIO4All 控制面板里改选了别的设备或输入／输出，REW 必须重新加载 ASIO4All 驱动，才能显示新可用的通道。做法是点击 ASIO 控制面板按钮右边的重新加载按钮。

用 Java 驱动时，列表里可能同时包含内置设备、外接设备，以及操作系统提供的默认驱动。



尽量直接选音频接口本身，不要选“主声音采集驱动程序”“主声音驱动程序”“Java Sound Audio Engine”这类操作系统驱动。

REW 要自动检测电平，就必须直接访问音频接口上的控制项；选了操作系统驱动，往往做不到这一点。Java Sound Audio Engine 还容易在播放时产生爆音和杂音，测量质量会因此下降。

设备选好之后，就可以选输入和输出了。

用 Java 驱动时，输入一般叫“LINE_IN”或“MICROPHONE”，输出一般叫“SPEAKER”或“LINE_OUT”。USB 接口上的名称可能不一样，比如输入可能标成“Digital Audio Interface”。ASIO 设备对可用输入输出的命名更具体，每个单声道通道都会单独列出。

如果用的是 USB 麦克风，而且它的校准文件里带灵敏度值，REW 必须读到输入音量设置才能正确显示 SPL。所以必须明确选定这只麦克风所用的输入设备和输入通道，不能停留在“默认设备”。

现在越来越多的 Windows 笔记本和台式机，会对立体声麦克风输入做降噪处理，把两个声道共有的内容压掉。UMIK-1 这类 USB 麦克风两个声道的信号完全相同，等于全部都是共有内容，低频可能被压得很厉害。

如果输入端有降噪处理的开关，务必把测量所用输入的降噪关掉。关闭方法：打开 Windows 的声音设置，在相关设置下选声音控制面板；在录制选项卡里选中要用的麦克风，点属性按钮，再切到高级选项卡；如果有启用音频增强复选框，确认它没有勾选。

WASAPI 独占模式的设备一般不受这类处理影响。

排查提示：如果不想让 REW 访问音频接口的音量控制，取消勾选控制输入音量和控制输出音量两个复选框。之后所有电平调整都要改用操作系统的音量控制，或音频接口自带的混音器来做。

多通道输入与输出

用 Java 驱动时，选完输入或输出，还可以再选具体通道。音频接口一般提供立体声输入输出，所以测量输入可以选 Left 或 Right；输出可以选 Left、Right，也可以选 Left+Right，把测量信号同时送到两个声道。

在 Windows 上，Java 自带驱动只提供立体声连接。即使所接的音频接口本身支持多通道，或者已经配置成多通道（比如输出多通道 PCM 音频的 HDMI 输出），也是如此。要取得多通道访问能力，请选该设备的 WASAPI 独占模式条目，或者改用 ASIO 驱动，也可以用 FlexASIO 这类 ASIO 封装驱动。

WASAPI 独占模式会按常见通道数逐一探测，最多到 16 通道，采样率最高到 1536 kHz。如果某个接口没有给出预期的通道数，可以在 roomeqwizard.vmoptions 文件里加一行，指定 REW 要探测哪些 WASAPI 独占通道数。例如 -DcsjsoundChannels=1,2,4,32 就表示只检查设备是否支持 1、2、4 或 32 通道。

在 macOS 和 Linux 上，配置为多通道的设备可以把全部通道都开放出来。下面是在 macOS 上从一块多通道声卡的 8 个输出里任选一个的例子。从“音频 MIDI 设置”那张截图可以看到，这块卡配置为 8 通道、16 位、48 kHz。

要注意 macOS 给这块卡排的通道顺序有点特别：后置声道排在侧环绕声道前面。REW 按顺序把通道标为 Left、Right、C、LFE、SL、SR、SBL、SBR，但在这块卡上，比如在 REW 里选 SL，实际出声的是音频接口上标着 Rear 的那个插口的左声道；选 SBL 出声的则是标着 Side 的插口的左声道。

除了这处顺序上的怪异，各通道都可以单独选择。遇到这类不常规的通道对应关系，用输出通道映射功能处理即可。





采样率选择

用 ASIO 驱动时，只要音频接口支持，最高可提供到 1536 kHz 的采样率。ASIO 建议用较大的缓冲区大小（也就是较高的延迟），采样率越高越要如此。高采样率下能不能稳定工作，取决于电脑的运算速度和内存容量。

Java 驱动在 macOS 上最高提供 192 kHz，在 Linux 上最高 1536 kHz；选用 WASAPI 独占模式的设备时，可用采样率取决于设备本身的能力。视操作系统和设备而定，有些设备可能只提供 44.1 kHz 和 48 kHz。

如果没有使用 WASAPI 独占模式，务必在操作系统里把输入和输出设备也配置成 REW 中所选的采样率，否则操作系统会在所选采样率和设备实际运行的采样率之间做重采样。

WASAPI 独占模式的设备分两种情况：一种提供多个采样率，这些采样率会出现在 REW 里供选择，设备就按所选值运行；另一种只能工作在单一采样率下，而且这个采样率要由其他途径设定。例如 RME 的音频接口可能要在 MADIface Series Settings 对话框里选采样率，在那里选定之后，该设备就只有这一个采样率可用。

做声学测量，建议用 44.1 kHz 或 48 kHz，除非这次测试确实需要 20 kHz 以上的结果（比如研究高音单元的谐振）。采样率再高只会增加内存占用、拖慢处理速度，并不会提高精度。

校准音频接口

用 USB 麦克风作输入时不需要这一步，直接跳到检查电平

音频输入和输出选定之后，REW 就可以对音频接口的频率响应（frequency response）做一次校准测量了。

这一步很重要：它能确认音频接口配置正确，尤其是确认监听功能没有开着——只要有一部分输入信号被绕回输出，测量结果就是无效的。

这次校准的结果还可以用来把音频接口自身的响应从测量中扣除。

  1. 把音频接口的线路输出或耳机输出，直接接到它自己的线路输入上。用哪个通道做测量就接哪个通道，而且要与输入通道选择框里选中的通道一致。如果这个接口的输入带幻象电源（phantom power），务必把幻象电源关掉，以免损坏输出端。
  2. 点击设置 → 声卡面板上的校准声卡...按钮，按弹出对话框里的说明操作。
  3. 测量结果应当比较平直，大部分频段内的起伏远小于 1 dB；但最低频和最高频会出现滚降（roll off），高频端往往还带一些波纹（ripple）。如果 20 Hz 到 20 kHz 之间起伏过大，REW 会给出警告，这样的测量结果不能用。下面是一条有效的测量结果，来自某台笔记本的内置声卡，20 Hz 以下滚降较快（图表纵轴为 1 dB/格）：

注意：从设置 → 声卡面板发起的音频接口测量，扫频范围一律是完整范围，一直到接口采样率的一半，与扫频结束频率的设置无关；而且声卡校准文件不会应用到这类接口测量上。

另外注意：声卡校准文件只在测它时所用的那个采样率下有效。采样率改了，就要在新的采样率下重新测一次音频接口。
