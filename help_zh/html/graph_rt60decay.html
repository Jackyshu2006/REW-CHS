RT60 衰减图

REW 的 RT60 衰减图采用频域（frequency domain）方法，因此考察混响时间（reverberation time）时，频率分辨率（frequency resolution）可以比常规做法高得多，倍频程分数也可以窄得多，即使在低频也是如此。

经典的 RT60 估算方法

混响时间通常用时域处理求得。各种 RT60 值都通过计算施罗德积分（Schroeder integral）的斜率来估算。施罗德积分画的是脉冲响应（impulse response）的能量（即各采样值的平方）经反向积分（backward integration）后的结果，反向积分就是从响应的末尾开始，逐点往前累加。T20、T30、REW 的 Topt 等不同的 RT60 指标，是在施罗德积分的不同区间上求最佳拟合直线（best fit line）得出的。

这种方法有一些局限。测量的本底噪声（noise floor）会改变施罗德积分的形状，使它弯曲。为减轻这种影响，人们采取了多种措施：先估算本底噪声的电平，再据此调整积分的起始位置和所用的初始值。

此外，倍频程频带滤波器存在群延迟（group delay），可能影响算出的混响时间，低频尤其明显。

这些滤波器的频率分辨能力（frequency discrimination）通常也较差，因为滤波器阶数一般取得较低，通常是 6 阶，以免加重群延迟问题。结果是，强烈的共振会对响应上邻近的频段产生掩蔽效应（masking effect）。

估算 RT60 的频域方法

混响时间也可以用频域处理来估算：计算一组短时傅里叶变换（short-time Fourier transform，STFT），观察其中各个切片（slice）的衰减。瀑布图和频谱图通常就是用 STFT 画出来的。

STFT 序列中的各个切片，可以在频域里用砖墙滤波器（brick wall filter）做倍频程频带滤波，这种滤波在时域上不会带来群延迟。这时，频率分辨能力由 STFT 所用时间窗的特性决定。起决定作用的通常是左时间窗的宽度和形状，也就是时间窗的上升时间（rise time）。

在频域里处理，可以很方便地改用窄得多的倍频程频带滤波器给出结果。这样就能把各个共振单独分辨出来，而且不会对混响时间的估算造成负面影响。

施罗德积分不适用于频域处理。STFT 切片记录了混响衰减和噪声。把每个时间步上的切片值连成一个数据序列，再用指数衰减加噪声函数（exponential decay plus noise function）去拟合，就能估算混响时间。

拟合时，如果左时间窗的宽度大于切片间隔，就必须考虑它对数据序列的影响。拟合还必须能容忍衰减数据非单调（non-monotonic）的特点，也就是说，数据在衰减过程中会有起伏，并不是一路下降。

实现细节

以下是 REW 实现 RT60 衰减分析的一些技术细节。

衰减数据

衰减数据由一系列傅里叶变换（Fourier transform）得出，每一次变换称为一个切片。第一个切片以脉冲响应的峰值为参考点，之后每个切片依次在时间上后移一个切片间隔。全部切片覆盖的总时长，就是“时间范围”设置的值。

每个切片都要加窗：左时间窗用汉宁窗（Hann window），宽度等于上升时间；右时间窗也用汉宁窗，宽度等于“时间窗宽度”设置的值。

请注意，在高频段，频域方法的本底噪声通常比经典方法高。原因是为了照顾低频段，FFT 时间窗必须取得较宽。改用更窄的时间窗和更短的上升时间，可以生成本底噪声更低的高频衰减数据。也可以考虑采用频率相关时间窗（frequency-dependent windowing，FDW），但 FDW 的实现通常使用对称时间窗，在低频会造成上升时间过长。

自动设置这样确定时间范围：先在 250 Hz、500 Hz 和 1000 Hz 用 1/1 倍频程 6 阶滤波器做一次常规的 T20 分析，取其中最长的 T20 作为时间范围，但最短不少于 500 ms。切片间隔的取法，是让时间范围内大约有 250 个切片，切片步长最大 100 ms。上升时间取时间范围的 2%，最大 400 ms。

每个切片的数据先做低通滤波，平滑到 1/48 倍频程，再按每倍频程 96 个点采样，得到一组对数间隔（log spaced）的数据。之后的倍频程频带滤波，作用在这组对数间隔数据的幅度平方上。所用的滤波核（kernel）在整个带宽内都为 1，只有两端的值为 0.5。

RT60 分析

对每一个频率，把各切片在该频率上的值连成一个数据序列，RT60 就由这个序列分析得出。分析前先扫描一遍数据，检查数据末端附近有没有急剧的下跌或上升。如果有，从那里往后的数据不参与分析。

分析的做法，是用一个指数衰减加噪声函数去拟合这些数据。函数如下：

f(t) = level*exp(-6*log(10)*t/t60) + noise

三个模型参数 level, t60 和 noise，通过使误差函数最小来确定。误差函数由各切片时刻上的函数值与衰减数据之差构成。

REW 用的误差是：以 dB 表示的衰减数据，与以 dB 表示的模型函数值之差的均方值。这个均方值还要用一个误差缩放函数（error scaling function）加权，对低于 -20 dB 的值给予较小的权重。

模型参数的初始估计值，来自对 -10 dB 到 -20 dB 范围内的衰减数据做最小二乘直线拟合（least squares line fit）。

模型误差只在衰减数据的一段子区间上计算。模型拟合的名义起点是衰减曲线上的 -5 dB 点，但起点距衰减开始至少要有 10 ms 或一个上升时间。无论如何，起点在衰减曲线上都不能低于 -10 dB。

需要注意，衰减数据与施罗德积分不同，通常不是单调的。所以“-5 dB 点”指的是响应最后一次穿过 -5 dB 的那个点。

REW 对衰减数据的幅度平方，应用了一种经过改编的 Lundeby 法，用来估算本底噪声，以及本底噪声与 RT60 衰减线的交点。拟合终点随后设在衰减曲线上更靠后的位置：从衰减开始算起，终点的距离是交点距离的两倍。如果 Lundeby 算法没有找到好的结果，拟合终点就取有效数据的末端。

REW 用 UNCMIN 的 Java 移植版（由 Steve Verrill 移植）求解最优的模型参数。UNCMIN 是一个无约束优化器（unconstrained optimiser），所以约束要另行施加：在最小化器向量的各分量代入模型函数之前，先对它们做修改。这一约束过程，是参数值从优化器空间变换到函数空间的一部分。

在最小化器空间中，与 level 和 noise 对应的参数，是模型值换算成 dB 后再缩放的结果；与 t60 对应的参数，是 T60 值的倒数再缩放的结果。各参数的取值上下限，根据初始估计值设定。

要在低频获得良好的选择性，上升时间通常要大于切片间隔。因此在计算模型拟合误差之前，必须先考虑左时间窗对衰减数据的影响。

做法是把左时间窗与衰减数据做卷积（convolution）。但参与卷积的不是各切片的衰减值本身，而是相邻切片衰减值之差，因为时间窗实际作用的正是衰减中的这部分差值。
