测量面板

测量面板列出已经测过或已经载入的测量，并显示每条测量的相关信息，其中包括一张频率响应缩略图。如果这条测量是从某个文件载入的，或者已经保存过，面板上还会显示对应的文件名。

点击某条测量即可选中它。

想让备注直接显示在列表里，打开设置 → 视图里的显示测量面板备注即可；也可以把鼠标停在某条测量上，备注会以提示框的形式浮现。

把测量拖到列表中的新位置就能重新排序。可以一条一条拖，也可以先用 Ctrl+左键或 Shift+左键选中多条，再整组拖动。

当测量列表处于激活状态时（当前选中项周围有一圈蓝色边框），还可以用键盘快捷键：全选 Ctrl+A、剪切 Ctrl+X、粘贴 Ctrl+V。

粘贴进来的测量会放在当前选中项的前面；如果当时没有选中任何一条，就放到列表末尾。

折叠视图

测量面板可以收窄，给图表让出更多屏幕空间。点面板上的 << 按钮即可收窄。

测量分组

测量可以归入分组，列表很长时便于管理。

点分组名旁边的箭头可以展开或折叠该分组。分组按名称的字母顺序排列，排在所有未分组的测量之前。分组还可以指定颜色。

点击某个分组，会出现两个按钮，分别用于保存和移除该分组内的测量。

把测量加入分组

在测量上点右键，菜单里有加入分组，可以把当前这一条测量、或者当前选中的全部测量归入某个分组。

选新建分组...会弹出一个对话框，用来给新分组起名字；也可以顺便指定颜色、写几句备注。

分组操作

点分组按钮 ，会弹出分组操作菜单。

菜单里有几条将所有…加入分组，省略号处是不同的测量类型，每条用来把这一类测量整批归入分组。

按文件名分组会用当前已载入文件的文件名建立分组，并把测量放进对应的分组里；之后新载入的文件也照此处理。 但是已经属于某个分组的测量不受影响。

叠加图（包括 All SPL 图）的分组菜单里另有一个选项：展开时选择分组测量。 勾选后，展开某个分组时，组内所有测量都会被选中。不勾选的话，第一次展开分组时，组内测量都是未选中的；以后再展开，会恢复成上一次的选中状态。

管理分组

管理分组会打开一张表，列出 REW 见过的所有分组。双击表格单元格即可改名。 选中表中的某些行，就可以把不再需要的分组删掉。这张表的大小可以调整。

编辑单个分组

在某个分组上点右键，会打开一个面板，用来编辑该分组的标题和备注。 用 Ctrl+TAB 和 Ctrl+Shift+TAB 可以在几个输入框之间切换，也可以依次翻看当前已载入的各个分组。 分组备注支持加粗、斜体和下划线：选中文字，再点面板下方的按钮即可。想插入链接，把链接打上去或粘贴进去，然后按一下空格。

筛选视图

测量列表可以筛选，只显示某几类测量，或者只显示名称中含有指定文字的测量。 部分测量类型带有淡色底色，便于区分；如果该测量属于某个已指定颜色的分组，则以分组颜色为准。

测量操作

在测量面板上点右键，会弹出一组控件，可以保存、移除、改曲线颜色、锁定测量、加入分组、改测量名称、查看和编辑备注，还有其他一些操作。 这个面板还会显示本次测量用过的麦克风／声压计校准文件和声卡校准文件。把鼠标停在那块文字上，会弹出提示框显示完整内容。 面板打开时，测量名称已处于选中状态，可以直接改。按 Ctrl+TAB 从名称跳到备注区。再按一次 Ctrl+TAB，面板会切换到列表中的下一条测量，到末尾后回到开头。按 Ctrl+Shift+TAB 则反向切换。 如果只想快速改个名字，在名称区域上点右键，会出现一个文本框供你编辑。

右键面板顶部的文本框用来改测量名称，名称长度以文本框宽度为限。 如果留空，REW 会填上“No Description”。 新测量、以及有改动尚未保存的测量，名称显示为蓝色。

已锁定的测量不能删除：移除操作会变灰，面板上会出现一个锁形图标。 按 Ctrl+U 可以解锁全部测量，按 Ctrl+L 可以锁定当前选中的那条测量。另外有“锁定所选项”和“解锁所选项”两个操作，用来锁定或解锁所有选中的测量。

针对每条选中的测量，还有以下操作：

  • 反相：改变该测量的极性。
  • EQ：打开均衡器窗口，并选中这条测量。
  • 加入分组：把该测量放进某个分组（选“无”则把它移出所有分组）。
  • 更改校准：打开一个对话框，用来载入、更新或清除麦克风／声压计和声卡的校准数据文件，也可以在这里指定本次测量是否使用了 C 计权声压计。 注意：改动校准数据或 C 计权设置，会清除已经生成的瀑布图、衰减图和频谱图——它们基于旧数据，已经不再有效。其他受影响的图表会用新的校准数据重新生成。


  • 响应副本：生成一份响应与原测量相同的副本。副本沿用原测量的脉冲响应（impulse response）和校准数据，但不带失真数据、均衡器设置这类内容。
  • 箱内麦克风校正：生成一条新测量，它带有源测量的 SPL 数据，并针对箱内麦克风法（microphone in box method）测量做了补偿修正。 修正的做法是加上一个 40*log10(f/f0) 的偏移量，其中 f0 是标称参考频率，取 50 Hz。这条结果通常会与远场（far field）测量合并。
  • 多余相位副本：把多余相位（excess phase）响应复制出来，供后续运算使用。副本的内容是原测量除以该测量的最小相位（minimum phase）版本。
  • 最小相位副本：把最小相位响应复制一份，供后续运算使用。副本带有最小相位的脉冲响应，幅度响应和校准数据与原测量相同。详见生成最小相位。
  • 幅度副本：生成一份副本，幅度响应与原测量相同，但不含脉冲响应和相位响应。
  • 合并校准至 IR：生成一份响应与原测量相同的副本，但它的脉冲响应里已经包含了该测量校准文件的影响。 如果校准数据存在大幅滚降（roll-off），脉冲响应中可能出现伪像（artefact）。另外，新测量会带上原测量的失真数据，但这批失真数据对应的基波仍沿用原测量的，不随合并而改变。
  • 按窗口裁切 IR：生成一份副本，其脉冲响应从左窗起点开始，长度缩短为能覆盖加窗区间的最小的 2 的整数次幂个采样点。 导出前想把 IR 缩短，或者运算结果的 IR 太长想裁掉一截，都可以用这个操作。

多选时的测量操作

先用 Ctrl+左键或 Shift+左键选中多条测量，再在测量面板上点右键，会弹出一组针对这批测量的操作：保存、移除、锁定、解锁、改颜色、更改校准数据、生成响应副本。
