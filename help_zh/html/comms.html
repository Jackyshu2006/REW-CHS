通信设置

“设置 → 通信”页签用来选择与均衡器通信所用的 MIDI 接口。



要选择 MIDI 端口，先勾选启用 MIDI。在 macOS 上，默认不能选择 MIDI 端口，因为在部分 Mac 上，访问 MIDI 会导致 Java 运行环境（Java Runtime Environment）崩溃。

如果使用的均衡器带有 REW 支持的 MIDI 接口，请选择一个 MIDI output port（MIDI 输出端口）。

REW 可以通过 MIDI 给 BFD Pro DSP1124P 和 FBQ2496 写入设置。设备一侧怎么设置，详见帮助页与 BFD Pro 通信。

注意：只有第一次打开“通信”页签时已经存在的端口，才能在这里选择。打开过这个页签之后再接上的接口，要重启 REW 才能识别。

FBQ 滤波器延迟用来设定 REW 向 FBQ2496 发送滤波器设置时，每发完一组要等待多久再发下一组。如果滤波器设置传输不稳定，加大这个延迟可能会有帮助。
