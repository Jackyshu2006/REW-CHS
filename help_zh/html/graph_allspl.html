All SPL 图


All SPL 图是一张叠加图（overlay graph），显示已经完成的全部测量（SPL 曲线、阻抗曲线，或两者都有）。

在这张图上可以：对所有选中的曲线（trace）求平均；对两条曲线做运算，生成一条新曲线；把两条曲线对齐；计算两条曲线之间的双耳互相关（Inter-Aural Cross Correlation，IACC）。

All SPL 图的操作

在图表上单击右键，会弹出一个操作菜单。菜单里的操作，作用于图例（legend）中选中的全部测量：


  • 平滑处理（smoothing）操作：用来修改所有选中曲线的分数倍频程（fractional octave）平滑设置。选好后，点应用按钮生效。
  • 对齐 SPL...：调整所有选中的 SPL 曲线，使它们在选定的频率范围内平均 SPL 相同。
  • 撤销 SPL 对齐：恢复为测量时的原始电平。
  • 移除 IR 延迟：当前选中的测量中，凡带有脉冲响应（impulse response，IR）的，都移除估算出的 IR 延迟。
  • 撤销 t=0 变更：把 t=0 恢复到测量时的状态。
  • 时间对齐：让当前选中的所有测量在时间上对齐。

    如果测量时用了时间基准（timing reference），即回环连接或声学时间基准，脉冲响应会按测量延迟值平移。如果算出测量延迟之后又对 IR 做过时间偏移，平移时也会把这部分偏移计入。没有用时间基准的测量，按估算的 IR 延迟平移。

    时间对齐只能用于带有脉冲响应的测量。
  • 对齐 IR 起始点：按各条 IR 的起始时间，对齐所有选中的测量。
  • 互相关对齐：对各测量加窗后的脉冲响应做互相关（cross correlation），据此把选中的测量在时间上对齐。对齐的参考，是选中测量里在列表中排在最前面的那一条；在列表里上下拖动测量，可以改变它们的顺序。

    做向量平均（vector averaging）之前，可以先用它对齐麦克风阵列的各路测量，或者同一声源在不同位置的多次测量。
  • 清除参考：不再把任何测量用作其他测量的参考。
  • RMS 平均：对执行这项操作时选中的各条曲线，求 SPL 值的 RMS 平均。

    计算过程是：先把 dB 值换算成线性幅度，再把各幅度平方、相加、除以测量条数，对结果开平方根，最后换算回 dB。

    这种平均不考虑相位，把各条测量当作非相干（incoherent）信号处理。如果只选中一条曲线，结果只含源测量的幅度数据，没有相位数据。

    如果各条测量是在不同位置做的（即空间平均，spatial averaging），通常最好先用对齐 SPL...功能，消除声源距离不同造成的整体电平差异。

    对带有失真数据的测量求平均时，失真数据也会一并平均，前提是这些数据的频率范围和分辨率都相同。
  • dB 平均：直接对当前选中曲线的 dB SPL 值求平均。

    这样得到的结果，更接近看着曲线凭直觉估计的样子。但它给峰和谷同样的权重，掩盖了两者在幅度上的实际差距。例如，+20 dB 峰的幅度是 -20 dB 谷的 100 倍；对两者做 dB 平均得到 0 dB，只有峰的十分之一，却是谷的 10 倍。

    如果要把几条平滑过的曲线平均，得出一条用作 EQ 目标的曲线，dB 平均可能比较合适。若用未经平滑的数据，曲线上的深谷会把平均结果拉低太多。

    对带有失真数据的测量求平均时，失真数据也会一并平均，前提是这些数据的频率范围和分辨率都相同。
  • 向量平均：对当前选中的曲线求平均，同时考虑幅度和相位。它只能用于带有脉冲响应的测量。最适合的场合，是在同一位置做的多次测量，或者求平均前已经做过时间对齐和电平对齐的测量。

    用向量平均对带有失真数据的测量求平均时，失真数据也会一并平均，前提是这些测量的采样率相同、扫频设置也相同。
  • RMS + 相位平均和 dB + 相位平均：幅度分别按 RMS 或 dB 求平均，相位则用向量平均。两者都只能用于带有脉冲响应的测量，适合对同一声源的多次测量求平均。

    求平均前，应先对各测量做时间对齐和电平对齐；时间对齐推荐用互相关对齐。

    向量平均时，相位抵消可能在幅度上造成凹陷；这两种平均方法不会出现这类凹陷。

    不过，这两种平均打破了幅度与相位之间通常存在的对应关系，所以平均得到的脉冲响应可能含有明显的非因果（acausal）成分。因此，这种平均结果需要比平常更宽的左时间窗（left window）。

    各条测量所用校准文件的影响，都会合并到平均得到的脉冲响应里。
  • 向量和：把当前选中的曲线相加，同时考虑幅度和相位。它只能用于带有脉冲响应的测量。
  • 导出 IR WAV：把选中测量的脉冲响应保存为 WAV 文件。
  • 导出 IR txt：把选中测量的脉冲响应保存为文本文件。
  • 导出为 txt：把选中的测量导出为文本文件。

  • 对齐工具：打开“对齐工具”对话框。

单选时的操作

在测量选择列表（selector）上单击右键，会弹出随当前图表变化的附加操作。在 All SPL 图上，这些附加控件一个用来调整 SPL 偏移，一个用来把这条测量设为其他测量的参考。

某条测量被设为参考后，它在选择列表上会带一条橙色色条；以另一条测量为参考的测量，则带一条紫色色条。这些以另一条测量为参考的测量，SPL 曲线会改为显示它们与参考之间的差值。

对齐工具

对齐工具用来调整一对测量的增益、极性（polarity）和延迟。调整参数时，两者相加的结果会实时预览。预览用的是每倍频程 96 个点（96 PPO）的对数间隔数据，因此可能与最终结果略有差异。图上还有一条虚线曲线，显示不考虑相位时两条测量相加的结果。

打开对齐工具后，All SPL 图的曲线选择会改为只显示参与对齐的两条曲线。需要的话，也可以在图例中另外选中其他曲线。关闭对齐工具后，原来的曲线选择会恢复。

测量 B 的延迟有两个滑块：一个用于粗调，一个用于微调，这样手动调整的范围更宽。对齐工具自动对齐测量时允许使用的延迟范围，由延迟范围 (ms)控件设定。

对齐工具有两种工作模式：相位对齐和脉冲响应对齐。


对齐副本按钮会生成所选测量的一个副本，并应用对齐时设定的增益、延迟和极性。对齐相加则按当前对齐设置把两条测量相加，生成一条新测量。

对齐工具：相位对齐

在相位对齐模式下勾选显示相位曲线后，All SPL 图会分成上下两部分：上面是 SPL 曲线，下面是两条选中测量的相位曲线。勾选显示相加结果的相位后，还会显示对齐相加结果的相位。

勾选移除时间延迟后，两条脉冲响应会一起平移，使测量 A 的 IR 从 t=0 开始。这样可以减少相位曲线上的相位缠绕（phase wrap）。


在光标处拉平相位按钮会计算一个延迟，使测量 A 的相位曲线在相位图光标（cursor）所在频率附近大致变成水平。两条测量都加上同一个延迟，所以对齐它们所需的相对延迟不受影响。这样平移相位曲线后，两条曲线更容易对齐。

这个延迟只用来更新相位曲线的显示，使用对齐副本或对齐相加时不会应用它。撤销拉平会把两条测量上用于拉平的延迟都去掉。

在光标处对齐相位斜率按钮会计算测量 B 所需的延迟，使两条相位曲线在相位图光标所在频率附近的斜率大致相同，也就是群延迟（group delay）大致相同。

请注意，斜率对齐后，两条相位曲线仍可能相距很远，尤其是两条测量相位相反时。这种情况下，把其中一条测量反转极性，就能让两条相位曲线靠近。

在光标处对齐相位按钮会计算测量 B 所需的延迟，使两条相位曲线在相位图光标所在频率附近尽可能靠近。

请注意，先把其中一条测量反转极性再对齐相位，或者手动调整延迟，或者两者结合，都可能得到更好的整体对齐效果。

对齐工具：脉冲响应对齐


在脉冲响应对齐模式下勾选显示脉冲响应后，All SPL 图会分成上下两部分：上面是 SPL 曲线，下面是两条选中测量的脉冲响应。

脉冲响应对齐的做法是：先用一个 1/3 倍频程的零相位滤波器（zero phase filter），在光标所在频率处对两条响应滤波，再把滤波后的响应对齐。下方滤波后脉冲响应图的时间跨度，会随对齐频率自动调整。



在光标处对齐 IR 按钮会在光标所在频率处应用滤波器，再对两条响应做互相关，找出最佳对齐位置。对齐结果可能需要把其中一条响应反转极性，上图的脉冲响应显示里就能看出这一点。下图是把低音炮曲线反转极性后的响应。



寻找最佳对齐位置时不受极性影响，这是脉冲响应对齐模式的优点。但如果所选对齐频率附近有很强的模态共振（modal resonance），共振可能在滤波后的响应中占主导，这时该模式可能难以把滤波后的响应对齐。

All SPL 图的图表选项

All SPL 图的图表选项里有以下控件：


勾选缩放时显示数据点后，放大到能分辨单个数据点时，图上会画出构成 SPL 响应和相位响应的各个数据点。这可能只出现在曲线的一部分范围内。

勾选显示频带后，图表上方会用一条色带标出各个音频频带。这些频带是：

  • Infrasound（次声）：20 Hz 以下
  • Sub bass（超低频）：20–60 Hz
  • Bass（低频）：60–250 Hz
  • Low midrange（中低频）：250–500 Hz
  • Midrange（中频）：500 Hz–2 kHz
  • Upper midrange（中高频）：2–4 kHz
  • Presence（临场感频段）：4–6 kHz
  • Brilliance（明亮度频段）：6–20 kHz

勾选显示模态频率后，图表底部会画出理论模态频率（modal frequency）。这些频率根据房间尺寸计算，所用尺寸是在 EQ 窗口模态分析部分为当前选中的测量填写的。

显示阻抗时，坐标轴范围是 0 到 1 千欧。如果需要更大的阻抗范围，可以勾选阻抗图使用对数坐标，把坐标轴切换为对数坐标，范围可达 1 吉欧。勾选后，凡是显示阻抗的地方都会使用对数坐标轴。

IEC 263 比例控件可以把图表锁定在指定的“dB/十倍频程”宽高比（aspect ratio）上。REW 会按需要调整图表四周的边距，来保持这个宽高比。

曲线选项按钮会弹出一个对话框，可以修改图表曲线的线型。
