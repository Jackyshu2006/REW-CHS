专业版升级

REW 专业版升级（Pro Upgrade）为专业用户增加了一些功能，目前包括同时从多个输入采集信号， 以及按 IEC 60268-16:2020 用间接法计算语音传输指数（speech transmission index，STI）。今后还会继续增加。

专业版升级许可证一次付费，解锁多通道测量（multi-input capture）和 STI，今后新增的专业功能也一并解锁。

多通道测量

多通道测量让 REW 同时从多个输入采集信号， 既可以用于测量，也可以用于 RTA。每个输入可以有各自的校准文件。 前四个输入可独立进行 SPL 计量，电平计量最多支持 32 个输入。

用多通道测量做出来的测量结果，显示的是所有采集通道幅度的 RMS 平均值，并用底色显示各通道的范围。 此外还可以选择保留每个通道各自的测量，也可以把任意几个输入编成分组，各组分别求平均。

多通道测量通常配合麦克风阵列（mic array）使用，例如 miniDSP UMIK-X； 也可以用一台多通道音频接口，外接多支模拟麦克风。REW 只能采集编号连续的一段输入通道。

在 Windows 上借助 ASIO 封装驱动（ASIO wrapper），也能把多支 USB 麦克风用于这个功能， 但不建议这么做，原因有两点：

  • REW 只能读到第一支 USB 麦克风的输入音量设置，然后拿这个值去换算所有麦克风的声压级。 也就是说，所有 USB 麦克风在操作系统里的音量必须调成一样。
  • USB 麦克风通常对外提供一对立体声输入，两个通道送的是同一份数据， 所以每支麦克风都会被采到两路完全相同的信号。

在 Windows 上用 Java 驱动时，要选 WASAPI 独占模式的设备条目才支持多通道， 也就是设备选择框里以 EXCL: 开头的那些条目。在 macOS 或 Linux 上， Java 驱动能提供的通道数，与音频接口本身支持的通道数相同。


一份许可证适用于单一用户，可在其使用的任意计算机上使用。

miniDSP UMIK-X 多通道麦克风系统已包含一份 REW 专业版升级许可证。

购买许可证之前，先确认 REW 在默认的单通道采集模式下已经能正常工作、满足你的需要。

要启用许可证，打开 REW 的“专业版升级”菜单，选择“多通道测量”， 把许可证代码粘贴进去，然后点击“验证许可证”。
