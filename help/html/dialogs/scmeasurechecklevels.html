The 1kHz tone is now playing. Adjust the Input Volume using the REW control (if enabled and available) or your interface's mixer or your OS audio level controls so that the input level is close to the output level, ideally within 6dB, and the peak level (the red line on the bar) is lower than -1dB.

If the input level control is at its maximum but the input level is still more than 6dB below the output level try increasing the Output Volume using the REW control (if enabled and available) or your interface's mixer or your OS audio level controls.

Press Next when the input volume has been set or Cancel to quit.
