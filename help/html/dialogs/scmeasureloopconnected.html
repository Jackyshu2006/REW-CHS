The first stage is to use a 1kHz tone to set the levels of the measurement signal and the interface input volume. The tone is generated at the current Sweep Level setting, it is best to use a fairly high level for interface measurement, between -12 and -6 dBFS. Set this level now using the Sweep Level control, the original level will be restored at the end.

If the REW volume controls are available and enabled the Output Volume should be around 0.5 if it affects the signal level. If REW volume controls are not available or not being used set the levels via the controls in your interface's mixer or your OS audio control panel.

Press Next when the Sweep Level and Output Volume have been set or Cancel to quit.
