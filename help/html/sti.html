Speech Transmission Index

The STI panel is used to calculate the Speech Transmission Index for an impulse response by the indirect method per IEC 60268-16:2020. Post-processing (optionally including auditory masking) may be applied using noise and signal octave band levels which can be measured by REW or entered manually by clicking on the values. Speech signal octave band levels can be calculated from the IR for a specified overall dBA level.


Calculating STI

To calculate STI for an impulse response that has been obtained through a sweep measurement select the measurement from the drop-down list and press Calculate STI. If post-processing is to be applied make sure the signal and noise level values have been measured or entered.

The results may be copied to the clipboard using the copy button.

Measuring or setting levels for post processing

The Measure noise and Measure signal buttons allow Leq figures in each octave band to be measured with the Leq period set on the dialog. While measuring noise or signal levels the octave band figures will update in the table row and the overall LAeq figure will be shown. If the REW generator is used when measuring signal levels the IEC 60268-16:2020 speech-shaped noise signal will be automatically selected and ready to play.

Signal or noise levels can be manually entered by clicking on a cell. Tab and shift+tab move forwards and backwards between cells. Levels can be uniformly increased or decreased in 1 dB increments using the +1 dB and -1 dB buttons.

The levels can be set from saved 1 octave RTA measurements using the Load signal Leq from and Load noise Leq from buttons.

Speech signal octave band levels can be calculated from the impulse response using the Calculate Leq at button for a specified overall dBA level. The calculation uses the windowed IR.
